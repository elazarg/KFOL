\paragraph{When merging roles acts on values.}
For a map $f:I\to J$, let $fG$ relabel every owner and terminal winner
of $G$ by $f$; equilibria are recomputed with the new objectives.
Say that $f$ \emph{descends} when games with the same old value always
have the same new value. This asks for an operation on the existing
winner observation, without retaining a game representative.

\begin{theorem}[Coalition maps on winner values]
\label{olv:thm:coalition-maps}
A role map $f:I\to J$ descends if and only if one of the following holds:
\begin{enumerate}[label=(\roman*)]
\item $f$ is injective;
\item $f$ is constant;
\item there are $c\in I$ and $q\in J$ with $f(c)\ne q$ and
$f(r)=q$ for every $r\ne c$.
\end{enumerate}
In case (iii),
\[
 \den{fG}=
 \begin{cases}
  \{f(c)\},&\den G=\{c\},\\
  \{q\},&\text{otherwise}.
 \end{cases}
\]
The direct image $S\mapsto f[S]$ preserves owned choices exactly
when $f$ is injective or constant. In every case
$\den{fG}\subseteq f[\den G]$.
\end{theorem}
\begin{proof}
An injection preserves the absorbing-singleton test, so direct image
commutes with every choice. A constant map gives its one terminal winner
throughout. In case (iii), the displayed map on values commutes with
choices: at a $c$-node the old value is $\{c\}$ exactly when some child
has that value; at any other owner's node it is $\{c\}$ exactly when
both children do. These are the two-player choice rules after merging.

For necessity, suppose $f$ is neither injective nor constant. Choose
$a\ne b$ with $f(a)=f(b)=q$, and $c$ with $f(c)\ne q$.
The game $G=\at b\ch a\at c$ has old value $\{b,c\}$ and new
value $\{q\}$. For any $d\notin\{b,c\}$ the game
$H=\at b\ch d\at c$ has the same old value. Its new value equals
$\{q\}$ only when $f(d)=q$: an owner $f(c)$ selects $\{f(c)\}$,
and an owner outside the two terminal teams leaves both possible.
Descent thus forces every role other than $c$ into team $q$, giving (iii).
This also supplies depth-one witnesses for every failure of descent.

For any noninjective, nonconstant map, the same game $G$ has
$f[\den G]=\{q,f(c)\}\ne\{q\}=\den{fG}$, excluding direct image.
Finally, at one choice, taking direct images can introduce a new
absorbing singleton and hence remove possible teams, but cannot add one.
Monotonicity of choice and induction on the game give the stated inclusion.
\end{proof}

For three original roles every role map descends, although the exceptional
two-team quotient is generally not direct image. Four roles already allow
failure: merge $a,b$ into one team and $c,d$ into another. The games
$\at b\ch a\at c$ and $\at b\ch d\at c$ both have old value
$\{b,c\}$, but after merging the first team wins the first game and
the second team wins the second.
