\section{What one player can see}\label{sec:perspectives}

Suppose we care only about whether a player $k$ can win. How much of a value matters? Two values look alike to $k$ if replacing a subgame of one value by a subgame of the other, anywhere inside a larger game, never changes whether $k$ can win. Some differences matter: if $x$ has value $\{i\}$, then in $x\ch i\at k$ player $i$ takes $x$ and $k$ loses, whereas if $x$ has value $\{i,j\}$ with $j\ne k$, player $i$ cannot force a win in $x$, and $k$ can win. Formally, working in $\A$, write $S\equiv_k T$ when $k\in f(S)\Leftrightarrow k\in f(T)$ for every term $f$ of $\A$ in one variable; since winner leaves build every value, these are the unary polynomials. This is contextual equivalence for the observation that $k$ can win, known in algebraic logic as the Leibniz congruence of the matrix that designates the sets containing $k$ \cite{BlokPigozzi1989,Font1993}.

\begin{proposition}[Player views]\label{view:thm:view}
$S\equiv_k T$ exactly when $S,T$ agree on whether they contain $k$ and on whether they equal $\{i\}$, for each $i\ne k$. So there are exactly $K+1$ classes:
$\pv$, the sets containing $k$; $a_i$, the atom $\{i\}$, for each $i\ne k$; and $\nv$, the ambiguous sets omitting $k$.
\end{proposition}

In words, $k$ needs to know whether it can win and, if not, whether another player is guaranteed the win, and which.

\begin{idea}
For $k\ne r$, the role $k$ belongs to $S\ow r T$ exactly when it belongs to an input and neither input is $\{r\}$. So this information is preserved by every operation. None of it can be dropped: the context $x\ow i\{k\}$ excludes $k$ exactly when $x=\{i\}$, so each other player's
atom is a trap that $k$ must recognize.
\end{idea}

Membership determines a set, so the $K$ views together are faithful, and every operation acts on each view separately: $\A$ is a subdirect product of the quotients $C_k=\A/{\equiv_k}$ (\cref{view:cor:product}). An equation therefore holds exactly when it holds in every view, which gives the small test sets of \cref{sec:pair-tests} and the countermodels of \cref{sec:no-basis}. In $C_k$ each $\star_r$ is the join of a small order. For $r\ne k$, the atoms $a_i$ with $i\ne r$ are incomparable and lie below $\nv$, then comes $\pv$, and the absorbing atom $a_r$ is on top. For $r=k$, all the atoms lie below $\nv$, then comes $\pv$.

Views differ from guarantees: forcing separates $\{k\}$ from $\{k,j\}$ (\cref{sec:rational}), whereas $k$'s view identifies them. Conversely, observing only unique winners collapses all ambiguous sets (\cref{game:prop:obs}) and leaves the coordinate operations of Olde Loohuis and Venema's guarantee algebra
\cite[Definition~3.20]{OldeLoohuisVenema2010}, restricted to its empty and singleton values. Possible winners retain what guarantees discard.

Internal renaming changes this picture. If $S,T$ differ at $i$, a renaming carrying $i$ to $k$ shows $k$ the difference, so the one-player quotient becomes equality. The congruences, the equivalences that all operations preserve, then form a chain: for each $m<K$, identify all sets with more than $m$ members (\cref{view:thm:sym}; those of $\A$ are described in \cref{view:thm:congruences}).
