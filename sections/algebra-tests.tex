\section{Testing equations on small inputs}\label{sec:pair-tests}

An equation quantifies over $2^K-1$ values per variable. Without internal switching, the views show that $K+2$ fixed values suffice for $K\geq4$ (\cref{view:cor:optimal}). The full signature needs more, though still few. Everything $\star_r$ does beyond union lies in one test: is an operand
exactly $\{r\}$? So assign each input variable a \emph{status}, either a specified atom or an unspecified ambiguous set. Such an assignment is a \emph{status cell}: it fixes every such test, and what remains is a union.

\begin{lemma}[Permutation provenance on a status cell]\label{sym:lem:provenance}
On every fixed status cell, a term denotes
\begin{equation}\label{sym:eq:provenance}
 C\ \cup\ \bigcup_j\ \bigcup_{\pi\in P_j}\pi S_j,
\end{equation}
where $S_j$ is the value of $x_j$, $C\subseteq I$, only ambiguous input variables occur in the union,
and every $P_j$ is a finite, possibly empty, set of permutations.
\end{lemma}

\begin{theorem}[Pair countervaluations]\label{sym:thm:pairs}
If an equation between terms of $\mathbf A^{\rm sym}$ fails, it fails at a valuation in which every variable has one or two possible winners.
\end{theorem}
\begin{proof}
Take a failed valuation, fix its statuses, and choose a role $k$ present
in the left output and absent from the right, interchanging sides if
necessary. Apply \cref{sym:lem:provenance} to both terms.

If $k$ lies in the left constant, it survives every valuation in the
cell. Otherwise it has a witness $k=\pi(i)$ for one ambiguous input
$S_j$, one coefficient permutation, and some $i\in S_j$. Replace that
input by a pair contained in it and containing $i$. Replace every other
ambiguous input by any pair contained in it. Leave atomic inputs fixed. The left witness remains. The right output can only shrink under
these replacements, since every coefficient is a permutation image and
the status cell is unchanged. It still excludes $k$.
\end{proof}

These inputs are all needed: a fixed set of inputs tests every equation, at every arity, exactly when it contains every atom and every two-element set (\cref{sym:thm:optimal}). So the unique minimum domain has $K(K+1)/2$ values. It is a set of inputs only, since intermediate results still range
over all values.
