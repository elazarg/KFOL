\section{What owned choices alone express}\label{sec:intrinsic}

Which operations combine their inputs without adding anything of their own? Call a term operation \emph{idempotent} if $t(S,\ldots,S)=S$ for every $S$, that is, if filling every variable with games of one value $S$ gives a game of value $S$. This semantic condition determines the syntax. For a variable occurrence, compose the role permutations on its path from the root.

\begin{theorem}[Idempotent elimination]\label{gen:thm:core}
A term is idempotent if and only if it has no winner leaves and every variable occurrence has identity accumulated permutation. Consequently the idempotent term operations are exactly those of $\mathbf C$, and an equivalent term can be extracted in polynomial time.
\end{theorem}

\begin{idea}
Evaluate the diagonal on ambiguous inputs. A winner leaf leaves a fixed nonempty constant in every output, but no role lies in all ambiguous sets. Without winner leaves every node is a union, so the value is $\bigcup\pi S$, and $\pi S\subseteq S$ for every pair forces $\pi$ to be the identity.
Conversely, $\pi(u\star_r v)=\pi u\star_{\pi(r)}\pi v$ pushes renamings to the leaves, where they vanish.
\end{idea}

So idempotency singles out $\mathbf C$. On ambiguous inputs a core term is the union of its variables, so identities between core terms have the same variables on both sides (\cref{gen:cor:trace}). Every idempotent operation, even one defined with internal renamings, respects each player's view (\cref{gen:cor:views}).

Which operations do core terms express? Each has a canonical normal form at every arity, and whether a given operation is a core term operation reduces to repeated tests of its singleton outputs (\cref{core:thm:source-guards,core:cor:guard-peeling}). No bounded amount of local evidence suffices, however: for every $m$, some $(m+3)$-ary operation agrees with a core term on any $m$ valuations without being one (\cref{core:thm:not-finitely-related}). So no finite family of relations closed under coordinatewise owned choice characterizes the core's term operations; in the terms of clone theory, the core is not finitely related.

Terms cannot branch on who wins a subgame: no term returns $y$ when $x=\{a\}$ and $z$ when $x=\{b\}$. This follows from the simplest constraint we know on what terms can do, which says that a term cannot switch the leaf its winners come from as the inputs change. A \emph{source occurrence} is a winner or variable leaf together with its accumulated permutation.

\begin{theorem}[One common source]\label{gen:thm:source}
Fix valuations $v_e$ and pairwise disjoint regions $W_e\subseteq I$. If $t(v_e)\subseteq W_e$ for every $e$, then one source occurrence of $t$ has its value inside $W_e$ in every valuation simultaneously. With at least two regions, it is a variable occurrence.
\end{theorem}
\begin{proof}
At an owned node with owner $r$, at most one region contains $r$.
In every other valuation the output cannot collapse to $\{r\}$;
it is union, so both children lie in the region. In the possible
exceptional valuation, either both children lie in the region or a
child is the absorbing owner atom and lies in it. Choose that child:
it works in all valuations. Descend to a leaf. At a renaming pull the
regions back along the permutation, preserving disjointness. A winner
leaf has the same nonempty value in all valuations and cannot fit
two disjoint regions.
\end{proof}

So three valuations in which every input repeats a value cannot produce three distinct atoms. With the three atoms as regions, \cref{gen:thm:source} would give one variable occurrence whose renamed value is the required atom in each valuation, but that occurrence repeats a value, and a renaming keeps the repetition. An if-then-else would do exactly this on the atomic inputs
\[
 \begin{array}{ccc|c}
 x&y&z&\text{if }x=\{a\}\text{ then }y\text{ else }z\\\hline
 a&a&a&a\\
 a&b&a&b\\
 b&a&c&c
 \end{array}
\]
in which every input repeats a value.

The same fact shows what determinism costs. Call a term \emph{atom-preserving} if it returns an atom whenever all its inputs are atoms, so that it induces a function $f:I^n\to I$. By the argument above, whenever three input tuples repeat a value in every coordinate, $f$ repeats a value among the three outputs. Such functions depend on at most one argument or take at most two values, by Szendrei's classification of the clone they form \cite{Szendrei2012} (\cref{gen:thm:S2}). An idempotent $f$ takes all $K\geq3$ values, so it depends on one argument, and idempotence makes it that argument.

\begin{corollary}[Determinacy]\label{gen:cor:determinacy}
An idempotent atom-preserving term projects one input on atomic valuations.
\end{corollary}

So a construction that adds nothing and turns unique winners into a unique winner just passes one subgame's winner through. What it can still do when some input is ambiguous is the subject of \cref{sec:reset}.
