\section{The complexity of equations}\label{sec:complexity}

\begin{theorem}[Pair dichotomy]\label{thm:raw-pairs}
Fix $K$. For a signature chosen from $\{\star_r:r\in I\}\cup\{\cup,\del\}$, equation validity is polynomial if the signature has at most one operation, and coNP-complete otherwise.
\end{theorem}

\begin{idea}
A single semilattice operation only sees variable supports, and reset is \cref{reset:thm:three}. For hardness, one device runs through the reductions; here it is for reset with union. The equation is $A\del R=R$, where $R$ already contains every input but one, $c$, unless its root input is atomic, when both sides collapse to that atom. So the sides can differ only by a winner of $c$. Since $c\del g$ keeps that winner exactly when $g$ is ambiguous, a chain of guards in $A$ is a conjunction.
A guard $t\cup\ell_1\cup\cdots\cup\ell_m$ with $t$ an atom is ambiguous exactly when some $\ell_i$ differs from $t$, which is a disjunction. Reading a literal as false when it equals $t$, we obtain conjunctive normal form. In $R$, each Boolean variable has a branch keeping $c$ when both its literals differ from $t$. An ambiguous $t$ makes these branches keep $c$, so a failing valuation has $t$ atomic and makes one literal of each variable equal to $t$, and this is an assignment.

Two owners use the same shape, reading a literal as false when it equals $\{a\}$. The $\star_b$-fold of a clause equals $\{a\}$ exactly when the clause is false, and $\star_a$ keeps a marker exactly when no operand equals $\{a\}$. A literal equal to $\{b\}$ makes both sides $\{b\}$. This containment and absorption is what turns a Boolean reading into equality of winner sets, which the Boolean reading alone does not give: it satisfies distributivity, and owned choice does not.
\end{idea}

\begin{corollary}[Equational complexity]\label{gen:thm:complexity}
Equational validity in $\mathbf C$, $\mathbf A$, and $\mathbf A^{\rm sym}$ is coNP-complete, at every fixed $K$ and with $K$ as part of the input.
\end{corollary}

Short certificates come from \cref{sym:thm:pairs}. So, unless $\mathrm P=\mathrm{NP}$, the core has no polynomial-time canonicalization with polynomial-time comparison.

Hard equality is compatible with a small equational basis. The fragment
$\{\star_a,\cup\}$ has exactly the identities of meet-distributive
bisemilattices \cite{HardingRomanowska2017}: the three semilattice laws for each operation and
distribution of $\star_a$ over union form a seven-equation basis
(\cref{core:prop:choice-union-basis}).

The tree representation matters. With shared subexpressions, even reset
alone has coNP-complete equality, already on its three-element generator
(\cref{reset:thm:circuits}). Sharing lets successive clauses reuse one
continuation; the resulting circuit has linear size although its
table can be large.

Preserving atoms does not help: $\{H_a,H_b\}$ is already coNP-complete (\cref{thm:H-hardness}). When $z$ is ambiguous, $H_s(z,y,u)$ keeps a winner of $u$ lying outside $z$ and $y$ exactly when $y\ne\{s\}$, and the atoms $\{a\}$ and $\{b\}$ are mutually exclusive values of $y$, which is all a Boolean variable needs.

Union also makes the number of roles visible. Reset has one equational theory for all $K$, but complete-graph coloring identities give $\{\del,\cup\}$ strictly fewer identities at each larger $K$ (\cref{thm:colouring-theories}).
