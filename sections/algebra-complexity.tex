\section{Where tractability ends}\label{sec:complexity}

Pair tests give a decision procedure for equations, but an exponential one: $|D_2|^n$ valuations for
$n$ variables. Reset, on the other hand, has polynomial equality. How much of owned choice can we add
to reset and stay polynomial? Very little, as it turns out, and the boundary can be drawn exactly.
\Cref{tab:complexity} summarizes the picture for fixed $K\geq3$.

The decision problem takes two ordinary tree terms, with any number of variables, and asks whether they
agree at every nonempty-set valuation. Fixing $K$ fixes the algebra and its signature. In the uniform
version, role names have binary encodings and permutations are explicit lists of their images. A succinct
encoding of terms by shared recursive descriptions is not assumed.

\subsection{The core is hard}

\begin{theorem}[Equational complexity]\label{gen:thm:complexity}
For every fixed $K\geq3$, equational validity is coNP-complete, already
in the signature with only variables and owned choices, without winner
constants or role switches. The uniform problem with $K$
as part of the input is coNP-complete as well.
\end{theorem}

\begin{idea}
Membership needs only a short certificate: a failed valuation at fixed $K$, or, uniformly in $K$, a
singleton-or-pair valuation from \cref{sym:thm:pairs}, evaluated on sparse sets. For hardness, fix roles
$a\ne b$ and read a set $S$ as true when $S=\{a\}$. On arbitrary nonempty inputs,
\[
 P(S\ow a T)=P(S)\lor P(T),\qquad
 P(S\ow b T)=P(S)\land P(T),
\]
so any monotone Boolean formula compiles directly into owned choices. To turn agreement of truth values
into equality of sets, take $W$ to be the union of all inputs: every constant-free term $u$ lies inside
$W$, so $u\ow a W$ is $\{a\}$ if $u$ is true and $W$ otherwise (the two cases agree when $W=\{a\}$). The
standard dual-rail encoding of CNF unsatisfiability then finishes the reduction. See
\cref{app:proofs-hard}.
\end{idea}

The gate uses the common input union as its false value, so it requires no named winner and no $I$. The
method is standard. Unless $\mathrm P=\mathrm{NP}$, the entire idempotent core has no polynomial-time
canonicalization with polynomial-time comparison. This does not preclude a finite equational basis or an
effective proof calculus.

\subsection{Hardness without owners, and the raw dichotomy}

One might suspect that hardness comes from owners, since their absorbing singletons are what distinguish
the algebra from a semilattice. It does not. All the reductions below use one device. Put a fresh winner in
an input $c$, and build a term in which $c$ survives only if a chain of guards are all ambiguous: this is
what reset does, since $c\del g$ keeps $c$ exactly when $g$ is ambiguous. A chain of guards is thus a
conjunction. And a guard such as
\[
 t\cup\ell_1\cup\cdots\cup\ell_m
\]
is ambiguous exactly when some $\ell_i$ differs from a resolved $t$, which is a disjunction. So conjunctive
normal form appears using nothing but reset and union: read a literal as false when it equals $t$.

\begin{theorem}[Owner-free hardness]\label{thm:owner-free-hardness}
For every fixed $K\geq3$, equation validity for the signature
$\{\del,\cup\}$ on $\Pow(I)$ is coNP-complete. It uses no constants,
owner names, or internal role switches.
\end{theorem}

The other side of the equation catches any inconsistent assignment, in the manner of dual-rail encoding
(\cref{app:proofs-hard}; \texttt{Fragments.lean} checks the semantic certificates). The same pattern, with folds in place
of unions, handles every other pair of basic operations.

\begin{theorem}[Raw-signature dichotomy]\label{thm:raw-pairs}
Fix $K\geq3$. For a signature chosen from
$\{\star_r:r\in I\}\cup\{\cup,\del\}$, equation validity is
polynomial-time decidable if the signature has at most one operation,
and coNP-complete otherwise. Each minimal hard pair has a linear-size
reduction in its native tree syntax.
\end{theorem}

\begin{idea}
For owners $a\ne b$, a $\star_b$-fold of literals equals $\{a\}$ only when all of them do, and a $\star_a$-fold
retains a marker only when none of its inputs is $\{a\}$. So
\[
 (m\star_a u_{C_1}\star_a\cdots\star_a u_{C_q})\ow b R= R,
\]
for clause folds $u_C$ and a suitable right-hand side $R$, encodes unsatisfiability with no use of $J$ and in
linear size. The pair $\{\star_a,\cup\}$ uses the same construction, and $\{\del,\star_a\}$ is the owner-free
reduction with $\star_a$ in place of union. Full proofs are in \cref{app:proofs-hard}.
\path{lean/RawFragments.lean} proves the fold tests, the absorption arguments, and the generic UNSAT transfer for the
owned guards; the CNF syntax assembly, size bounds, and complexity conclusions are written proofs, and
\path{checks/check_raw_pairs.py} evaluates the actual native reductions independently.
\end{idea}

\subsection{Hardness among atom-preserving operations}

Perhaps determinism helps? Recall the ternary witness $H_s(x,y,z)=(y\star_s z)\del x$ of \cref{sec:reset}. Each
$H_s$ is idempotent and atom-preserving, and reset is already definable by
\[
 x\del y=H_s(y,x,x).
\]

\begin{theorem}[Two atom-preserving operations suffice]\label{thm:H-hardness}
For $K\geq3$ and distinct $a,b\in I$, equation validity for
$\{H_a,H_b\}$ on $\Pow(I)$ is coNP-complete, without constants.
\end{theorem}

\begin{idea}
When $z$ is ambiguous, $H_s(z,y,u)$ retains a marker from $u$ exactly when $y\ne\{s\}$. Nest these along a
clause, with $s=a$ for positive literals and $s=b$ for negative ones, and read variable $i$ as true when
$y_i=\{a\}$. A falsified clause keeps the marker; and when every $y_i$ is $\{a\}$ or $\{b\}$, only a falsified
clause does. The two singletons are mutually exclusive values of $y_i$, and that is all a Boolean variable needs. See \cref{app:proofs-hard}.
\end{idea}

So these results exclude polynomial-time equality for reset with union and for the full idempotent atom-preserving clone,
unless $\mathrm P=\mathrm{NP}$. They do not exclude all tractable owner-sensitive fragments, as the next section shows.

\subsection{The number of roles becomes observable again}

Reset has the same theory for every $K\geq3$. Adding union changes that, even though neither operation names an owner. Let
$\mathcal B_K=(\Pow(\{1,\ldots,K\});\del,\cup)$.

\begin{theorem}[Strict dependence on the role count]\label{thm:colouring-theories}
For every $K\geq3$,
$\operatorname{Eq}(\mathcal B_{K+1})\subsetneq
 \operatorname{Eq}(\mathcal B_K)$.
\end{theorem}

\begin{idea}
The guards $x_u\cup x_v$ express proper colorings of a complete graph: a marker survives only if the $x_i$ are pairwise
distinct singletons, or else some input is ambiguous, in which case the other side has it too. On $n$ distinct singletons a
further fresh marker needs an unused role, and that is precisely what fails at $K=n$ but succeeds at $K=n+1$. See
\cref{app:proofs-hard}; \texttt{Fragments.lean} has the generic pigeonhole certificate.
\end{idea}
