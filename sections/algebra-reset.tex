\section{Reset}\label{sec:reset}

By \cref{gen:cor:determinacy}, an idempotent atom-preserving term projects one input on atomic valuations, so at binary arity only its behavior on inputs that are not all atoms remains. We call the following operation \emph{reset}:
\begin{equation}\label{reset:eq:reset}
 S\del T=\begin{cases}T,&T\text{ an atom},\\S\cup T,&T\text{ ambiguous}.\end{cases}
\end{equation}
An atomic right operand discards the left one, and an ambiguous one keeps it. Reset is definable by owned choices: start with $S\cup T$ and apply $U\mapsto U\star_r T$ once for each role. As a game, every player in turn may move play to the right operand. A player moves when that operand guarantees it the win, so an atomic right operand prevails, while an ambiguous one guarantees nobody anything and leaves every winner of either side possible. Reset accounts for all the remaining behavior.

\begin{theorem}[Binary atom-preserving operations]\label{reset:thm:binary}
The binary atom-preserving operations of $\mathbf C$ are exactly $x$, $y$, $x\del y$, and $y\del x$.
\end{theorem}

\begin{idea}
Suppose the term projects $x$. Freezing $x=\{r\}$ leaves a unary expression whose only constant is $\{r\}$, and such an expression is either constantly $\{r\}$ or contains its input (\cref{reset:lem:rigidity}). So an atomic $x$ decides the outcome. If $x$ is ambiguous, the same rigidity makes the term
contain $x$, and an occurrence of $y$ cannot be suppressed, which gives $y\del x$.
\end{idea}

Arity three goes further. For a role $a$, the \emph{guarded choice} of $a$ is
\begin{equation}\label{reset:eq:guarded}
 H_a(x,y,z)=(y\star_a z)\del x.
\end{equation}
It returns $x$ when $x$ is an atom, and otherwise adds $a$'s choice between $y$ and $z$ to $x$. It is idempotent and atom-preserving, yet it tests whether an input is the atom of a particular role, which reset never does: with $x=\{a,b\}$ and $z=\{c\}$, its value omits $c$ at $y=\{a\}$ and contains $c$ at $y=\{b\}$. We return to it in \cref{sec:complexity,sec:one-owner}.

A \emph{reset term}, built from variables by $\del$ alone, decides which inputs get through. Its \emph{root} is its rightmost variable, and it is ambiguous exactly when its root is. In $(x\del y)\del z$, the input $z$ is always kept, $y$ is kept when $z$ is ambiguous, and $x$ is kept when both are. In general, each input $j$ has a \emph{table}
$\mathcal G_j(t)$: the antichain of minimal sets of inputs whose ambiguity makes $j$ contribute (\cref{reset:lem:selection}). For $(x\del y)\del z$ the tables are $\{\varnothing\}$ for $z$, $\{\{z\}\}$ for $y$, and $\{\{y,z\}\}$ for $x$. One traversal of a term collects at most one such set per variable occurrence, and deleting nonminimal sets gives the tables, which are therefore small as well as complete.

\begin{proposition}[Canonical tables]\label{reset:thm:three}
Two reset terms are equal on all valuations if and only if their tables agree, and this can be tested on the fixed chain
$Z=\{a\}\subset U=\{a,b\}\subset T=\{a,b,c\}$. So equality is polynomial, and reset has the same identities for every $K$.
\end{proposition}

\begin{idea}
If tables differ, some input $j$ is selected by one term and not the other at some set of ambiguous inputs. Give $j$ the value $T$, the rest of that set the value $U$, and everything else $Z$. Whether $j$ is selected does not depend on $j$'s own status, so $c$ appears exactly when it is.
\end{idea}

The chain is closed under reset, and it is a known algebra: the order algebra $O_{2+1}$ of Freese et al., and the dual of $G_3$ in Waldhauser's work on almost associative operations generating a minimal clone \cite{FreeseEtAl2002,Waldhauser2006}. So reset has a complete calculus at once.

\begin{proposition}[Finite basis, after Freese et al.]\label{reset:thm:basis}
An equation between reset terms holds on all valuations if and only if it follows in equational logic from
\begin{alignat*}{2}
 &\text{(R1)}\quad x\del x=x,\qquad&&\text{(R2)}\quad (x\del y)\del x=y\del x,\\
 &\text{(R3)}\quad (x\del y)\del y=x\del y,\qquad&&\text{(R4)}\quad x\del((x\del y)\del z)=x\del(y\del z),\\
 &\text{(R5)}\quad ((x\del y)\del z)\del y=(x\del z)\del y,\qquad&&\text{(R6)}\quad x\del(y\del z)=y\del(x\del z).
\end{alignat*}
\end{proposition}

Tables can record alternatives. In $((x_3\del x_1)\del x_0)\del((x_3\del x_2)\del x_0)$, input $3$ contributes when $0$ and either $1$ or $2$ are ambiguous, and no single partial order of prerequisites says this. The right object is an \emph{antimatroid} on a set $X$: a union-closed family of feasible subsets of $X$, containing $\varnothing$
and $X$, in which every nonempty member can lose one element and remain feasible. Here $X$ is the set of variables of a term, and its feasible sets are those it selects entirely when exactly they are ambiguous. For $(x\del y)\del z$ they form the chain $\varnothing\subset\{z\}\subset\{y,z\}\subset\{x,y,z\}$, a single priority order. In the term above, $\{0,1,3\}$ and $\{0,2,3\}$ are feasible but $\{0,3\}$ is not, so input $3$ may follow either $1$ or $2$.

\begin{theorem}[Antimatroid representation]\label{reset:thm:anti}
Fix a set of inputs. The operations of reset terms correspond bijectively to the antimatroids whose ground set is a finite nonempty set of inputs and which have exactly one feasible singleton.
\end{theorem}

Tables are the single-rooted dependency structures with choice of Bazerman et al., whose correspondence with antimatroids is theirs \cite{BazermanMinichielloPuzio2023}, and Freese et al.'s path normal form, taken maximally and read backwards, lists the orderings of $X$ all of whose prefixes are feasible (\cref{reset:rem:priority}). What tables add is a compact form, with polynomial recognition and synthesis and a substitution formula (\cref{app:proofs-reset}).
