\section{Reset}\label{sec:reset}

At binary arity, \cref{gen:cor:determinacy} leaves only the behavior on inputs that are not all atoms, and one operation accounts for it:
\begin{equation}\label{reset:eq:reset}
 S\del T=\begin{cases}T,&T\text{ an atom},\\S\cup T,&T\text{ ambiguous}.\end{cases}
\end{equation}
An atomic right operand discards the left one, and an ambiguous one keeps it. Reset is definable by owned choices: start with $S\cup T$ and apply $U\mapsto U\star_r T$ once for each role.

\begin{theorem}[Binary atom-preserving operations]\label{reset:thm:binary}
The binary atom-preserving operations of $\mathbf C$ are exactly $x$, $y$, $x\del y$, and $y\del x$.
\end{theorem}

\begin{idea}
Suppose the term projects $x$. Freezing $x=\{r\}$ leaves a unary expression whose only constant is $\{r\}$, and such an expression is either constantly $\{r\}$ or contains its input (\cref{reset:lem:rigidity}). So an atomic $x$ decides the outcome. If $x$ is ambiguous, the same rigidity makes the term
contain $x$, and an occurrence of $y$ cannot be suppressed, which gives $y\del x$.
\end{idea}

Arity three goes further. The operation $H_a(x,y,z)=(y\star_a z)\del x$ is idempotent and atom-preserving, but it can see an owner: with $x=\{a,b\}$ and $z=\{c\}$, its value omits $c$ at $y=\{a\}$ and contains $c$ at $y=\{b\}$. We return to it in \cref{sec:complexity,sec:one-owner}.

A reset term decides which inputs get through. Its \emph{root} is its rightmost variable, and it is ambiguous exactly when its root is. In $(x\del y)\del z$, the input $z$ is always kept, $y$ is kept when $z$ is ambiguous, and $x$ is kept when both are. In general, each input $j$ has a \emph{table}
$\mathcal G_j(t)$: the antichain of minimal sets of inputs whose ambiguity makes $j$ contribute (\cref{reset:lem:selection}). One traversal of a term computes its tables, and they are complete.

\begin{proposition}[Canonical tables]\label{reset:thm:three}
Two reset terms are equal on all valuations if and only if their tables agree, and this can be tested on the fixed chain
$Z=\{a\}\subset U=\{a,b\}\subset T=\{a,b,c\}$. So equality is polynomial, and reset has the same identities for every $K$.
\end{proposition}

\begin{idea}
If tables differ, some input $j$ is selected by one term and not the other at some set of ambiguous inputs. Give $j$ the value $T$, the rest of that set the value $U$, and everything else $Z$. Whether $j$ is selected does not depend on $j$'s own status, so $c$ appears exactly when it is.
\end{idea}

The chain is closed under reset, and it is a known algebra: the order algebra $O_{2+1}$ of Freese et al., and the dual of $G_3$ in Waldhauser's classification of minimal clones \cite{FreeseEtAl2002,Waldhauser2006}. So reset has a complete calculus at once.

\begin{proposition}[Finite basis, after Freese et al.]\label{reset:thm:basis}
An equation between reset terms holds on all valuations if and only if it follows in equational logic from
\begin{alignat*}{2}
 &\text{(R1)}\quad x\del x=x,\qquad&&\text{(R2)}\quad (x\del y)\del x=y\del x,\\
 &\text{(R3)}\quad (x\del y)\del y=x\del y,\qquad&&\text{(R4)}\quad x\del((x\del y)\del z)=x\del(y\del z),\\
 &\text{(R5)}\quad ((x\del y)\del z)\del y=(x\del z)\del y,\qquad&&\text{(R6)}\quad x\del(y\del z)=y\del(x\del z).
\end{alignat*}
\end{proposition}

Tables can record alternatives. In $((x_3\del x_1)\del x_0)\del((x_3\del x_2)\del x_0)$, input $3$ contributes when $0$ and either $1$ or $2$ are ambiguous, and no single partial order of prerequisites says this. The right object is an \emph{antimatroid} on a set $X$: a union-closed family of feasible subsets of $X$, containing $\varnothing$
and $X$, in which every nonempty member can lose one element and remain feasible. Here $X$ is the set of variables of a term, and its feasible sets are those it selects entirely when exactly they are ambiguous.

\begin{theorem}[Antimatroid representation]\label{reset:thm:anti}
Reset term functions on a fixed set of inputs correspond bijectively to antimatroids with one feasible singleton on nonempty sets of those inputs.
\end{theorem}

Tables are the dependency structures with choice of Bazerman et al., whose correspondence with antimatroids is theirs \cite{BazermanMinichielloPuzio2023}, and Freese et al.'s path normal form, taken maximally and read backwards, lists the orderings of $X$ all of whose prefixes are feasible (\cref{reset:rem:priority}). What tables add is a compact form:
\cref{app:proofs-reset} gives polynomial recognition and synthesis, a substitution formula, and free-algebra sizes $1,4,18,140,2980$.
