\section{Reset: a fragment we understand completely}\label{sec:reset}

\Cref{gen:cor:determinacy} says that an idempotent atom-preserving term must project one input on
atomic valuations. At binary arity this is very nearly a complete description. What is left free is
the behavior on ambiguous inputs, and there the answer is a single operation:
\begin{equation}\label{reset:eq:reset}
 A\del B=\begin{cases}B,&|B|=1,\\A\cup B,&|B|\geq2.\end{cases}
\end{equation}
Think of $B$ as the current state of affairs and $A$ as a further possibility. If $B$ is already
resolved, the extra possibility is discarded; if $B$ is ambiguous, it is kept. Reset is realized by
starting with $J(A,B)$ and applying $U\mapsto U\star_r B$ once for each role. If $B=\{r\}$, that
owner's suppression selects it and all later owners preserve it; if $B$ is ambiguous, every step
preserves $A\cup B$. The order of the suppressions is immaterial.

Reset commutes with every role permutation, and its language consists only of variables and $\del$. It
cannot express arbitrary owned choice or ordinary union: reset preserves singleton-valued inputs, whereas
an owned choice between two other winners can return their pair.

\subsection{Why reset}

A term \emph{preserves atoms} if it returns a singleton whenever all inputs are singletons.

\begin{theorem}[Exact binary atom-preserving fragment]\label{reset:thm:binary}
For $K\geq3$, the binary atom-preserving operations definable by
constant-free owned choices are exactly
\[
 x,\qquad y,\qquad x\del y,\qquad y\del x.
\]
Hence the reset clone is exactly the part generated by the binary
operations of the idempotent, atom-preserving owned-choice clone.
\end{theorem}

\begin{idea}
Suppose the atomic restriction projects $x$. Freezing $x=\{r\}$ leaves a unary expression in $y$ whose only
constant is $\{r\}$, and such an expression is rigid: it is either constantly $\{r\}$ or contains its input
(\cref{reset:lem:rigidity}, kernel-checked in \texttt{OneConstant.lean}). Since it returns $\{r\}$ on atoms, it is
constant. So a resolved $x$ decides the outcome. If $x$ is ambiguous and $y$ too, every node is a union. If $y=\{r\}$,
the same rigidity makes the term contain $x$, and an occurrence of $y$ cannot be suppressed by any other owner, so
the value is $x\cup\{r\}$. These cases are exactly $y\del x$. See \cref{app:proofs-reset}.
\end{idea}

\Cref{gen:thm:core} extends this characterization to idempotent full-signature terms, including constants and
internal switches in their original syntax.

The binary restriction is strict. For an owner $a$, the ternary operation
\[
 H_a(x,y,z)=(y\star_a z)\del x
\]
is idempotent and atom-preserving. Set $x=\{a,b\}$ and $z=\{c\}$. At $y=\{a\}$ its value omits $c$, while at $y=\{b\}$
it contains $c$. The ambiguity statuses are unchanged, and only $z$ supplies $c$, so the selector semantics below rules out
a reset expression for $H_a$. Reset is the intrinsic binary core, while higher-arity atom-preserving operations retain
owner-sensitive behavior. We return to $H_a$ in \cref{sec:complexity,sec:one-owner}.

\subsection{What a reset term selects}

Evaluating a reset term is a matter of deciding which inputs get through. Let $N$ be the finite set of input positions,
including any declared unused positions. For a valuation $S=(S_j)_{j\in N}$ put $B=\{j:|S_j|\geq2\}$, a set of input
positions rather than of winner roles. The \emph{root} $\rho(t)$ is the rightmost variable:
\[
 \rho(x_j)=j,\qquad \rho(s\del t)=\rho(t).
\]

\begin{lemma}[Resolution and selection]\label{reset:lem:selection}
A reset term is ambiguous exactly when its root input is ambiguous.
There is a selector $E_t:2^N\to2^N$ with
\begin{align*}
 E_{x_j}(B)&=\{j\},\\
 E_{s\del t}(B)&=E_t(B)\cup
 \begin{cases}E_s(B),&\rho(t)\in B,\\\varnothing,&\rho(t)\notin B,\end{cases}\\
 t(S)&=\bigcup_{j\in E_t(B)}S_j.
\end{align*}
Every selector is monotone, always selects its root, and selecting
position $j$ is independent of whether $j$ itself belongs to $B$.
\end{lemma}

The proof is a direct induction (\cref{app:proofs-reset}); this exact mixed-input semantics is
\path{ResetCalculus.Term.denote_membership} in Lean. In $(x\del y)\del z$, for instance, $z$ is always kept, $y$ is kept
when $z$ is ambiguous, and $x$ is kept when both $y$ and $z$ are ambiguous. So what a term computes is a table of
prerequisites. For each position $j$, record the inclusion-minimal sets $A\subseteq N$ such that $j\in E_t(A)$. Denote this
antichain by $\mathcal G_j(t)$; an empty antichain means the position is unused. Then
\begin{equation}\label{reset:eq:guards}
 j\in E_t(B)\quad\Longleftrightarrow\quad
       \exists A\in\mathcal G_j(t)\; A\subseteq B.
\end{equation}
For the root the antichain is $\{\varnothing\}$, and every other antichain omits $\varnothing$. No minimal prerequisite for $j$
contains $j$, by self-independence.

These tables are computed directly. A variable contributes its empty guard. At $s\del t$, retain the right table and add
$\rho(t)$ to each left guard, then delete duplicates and every guard containing a smaller one for the same output. Before
minimization there is at most one guard per variable occurrence, so a tree traversal can collect and normalize them in
polynomial time.

\begin{theorem}[Canonical equality and three-element completeness]
\label{reset:thm:three}
Two reset terms are equal on all nonempty-set valuations if and only if
their prerequisite tables agree. The result is independent of $I$ for
every $|I|\geq3$. It suffices to evaluate on a fixed three-element chain
\[
 Z=\{a\}\subset U=\{a,b\}\subset T=\{a,b,c\}.
\]
Consequently equality is decidable in polynomial time in reset-tree size.
A failed equality has a polynomially constructible countervaluation
using only $Z,U,T$.
\end{theorem}

\begin{idea}
If two tables differ, some position $j$ is selected by one term and not the other at some $B$. Mark $j$ with the top value
$T$, give the rest of $B$ the value $U$, and everything else $Z$. Self-independence says that making $j$ ambiguous does not
change whether $j$ is selected, and the winner $c$ then appears exactly when it is. The result is
\path{ResetCalculus.Term.three_chain_complete} in Lean; see \cref{app:proofs-reset}.
\end{idea}

The chain is closed under reset. Numbering it $0<1<2$, its table is
\begin{equation}\label{reset:eq:three-table}
\begin{array}{c|ccc}
\del&0&1&2\\\hline
0&0&1&2\\
1&0&1&2\\
2&0&2&2
\end{array}
\end{equation}
This small algebra is an old acquaintance. It is the dual of $G_3$ in Waldhauser's classification
\cite[Theorem~3.4, table $G_3$]{Waldhauser2006}, under $0\mapsto b$, $1\mapsto a$, $2\mapsto c$. It is also exactly the order
algebra $O_{2+1}$ of Freese et al.\ \cite[Section~3]{FreeseEtAl2002}, whose poset has $a<b$ and an isolated $c$, with
$x\cdot y=x$ if $x\leq y$ and $y$ otherwise; the isomorphism from our labels is $0\mapsto c$, $1\mapsto b$, $2\mapsto a$. So the reset variety is
the variety generated by this established three-element algebra.

\begin{corollary}[Minimum finite generator]\label{reset:cor:generator}
The three-element algebra generates the common variety of all reset
algebras on $\Pow(I)$ for $|I|\geq3$, and no smaller algebra generates
that variety.
\end{corollary}

This is a bound on the carrier size of a generator, not on the arities available in a clone on a larger carrier. Even a
two-value input domain that is not closed under reset cannot test all identities: associativity holds whenever its three
arguments use at most two distinct winner sets. A failure requires the middle argument to be atomic and the last ambiguous,
with a contribution of the first lying outside their union, and two distinct input values cannot supply that contribution.

\subsection{A finite calculus, imported}

The identification with $O_{2+1}$ has an immediate and pleasant consequence.

\begin{theorem}[Known reset basis]\label{reset:thm:basis}
For every $K\geq3$, an equation between reset terms holds on all
nonempty winner-set valuations if and only if it follows in equational
logic from
\begin{align*}
 x\del x&=x,\tag{R1}\\
 (x\del y)\del x&=y\del x,\tag{R2}\\
 (x\del y)\del y&=x\del y,\tag{R3}\\
 x\del((x\del y)\del z)&=x\del(y\del z),\tag{R4}\\
 ((x\del y)\del z)\del y&=(x\del z)\del y,\tag{R5}\\
 x\del(y\del z)&=y\del(x\del z).\tag{R6}
\end{align*}
\end{theorem}
\begin{proof}
Freese et al.\ \cite[Theorem~3.7]{FreeseEtAl2002} prove that their
equations (E1)--(E5), together with left commutation, form a basis for
$O_{2+1}$. These are exactly (R1)--(R6) under the displayed isomorphism.
Theorem~\ref{reset:thm:three} identifies the identities of that algebra with
those of winner-set reset for every $K\geq3$.
\end{proof}

The inference rules are the ordinary rules of equational logic: reflexivity, symmetry, transitivity, substitution, and congruence
under $\del$. This is an application of the published basis, not a new one. Soundness of the six equations is kernel-checked in
\texttt{Reset.lean}; the completeness argument uses the external theorem and has not been mechanized. The result concerns reset, not
the larger owned-choice signature. The same source also develops common-root path normal forms and a suffix criterion for comparing
them, and \cref{app:proofs-reset} sets out the exact correspondence with our guards.

\subsection{The antimatroid represented by a term}

Prerequisites can describe alternative routes. Let
\[
 t=((x_3\del x_1)\del x_0)\del((x_3\del x_2)\del x_0).
\]
Its canonical table is
\[
 \mathcal G_0=\{\varnothing\},\quad
 \mathcal G_1=\mathcal G_2=\{\{0\}\},\quad
 \mathcal G_3=\{\{0,1\},\{0,2\}\}.
\]
Input $0$ is always retained, inputs $1,2$ are retained when $0$ is ambiguous, and input $3$ additionally requires either $1$ or $2$ to
be ambiguous. No single partial order of prerequisites describes such an alternative. The natural combinatorial object is the family of
\emph{feasible} sets, recording which positions can be reached by following the alternatives.

We use the standard finite feasible-set definition \cite[Section~7]{Czedli2014}. An \emph{antimatroid} on its actual support $X$ is a
union-closed family $\mathcal F\subseteq2^X$ containing $\varnothing$ and $X$, with the accessibility property: every nonempty feasible
set can lose one element and remain feasible. We require exactly one feasible singleton $\{r\}$. Accessibility then makes $r$ belong to every
nonempty feasible set. Unused input positions lie outside $X$. Write
\[
 \bas_{\mathcal F}(B)=\bigcup\{A\in\mathcal F:A\subseteq B\},\qquad
 e_{\mathcal F}(B)=\{j:j\in\bas_{\mathcal F}(B\cup\{j\})\}.
\]
The basis is the largest feasible subset of $B$, and $e_{\mathcal F}(B)$ consists of that basis together with its available one-element
extensions.

\begin{theorem}[Exact antimatroid representation]\label{reset:thm:anti}
Reset term functions on a fixed input set $N$ correspond bijectively to
antimatroids with one feasible singleton on nonempty supports
$X\subseteq N$. The correspondence is
\[
 E_t=e_{\mathcal F_t},\qquad
 \mathcal F_t=\{A\subseteq X:A\subseteq E_t(A)\}.
\]
For reset itself the family operation is
\begin{equation}\label{reset:eq:family-product}
 \mathcal F\del\mathcal G=
 \{\varnothing\}\cup
 \{A\cup C:A\in\mathcal F,\ C\in\mathcal G\setminus\{\varnothing\}\}.
\end{equation}
The root of the product is the root of $\mathcal G$.
\end{theorem}

\begin{idea}
The product family is union-closed and accessible: order $C$ first, then $A$, skipping repeats. Its basis is empty when the root $r$ is
outside $B$, and is $\bas_{\mathcal F}(B)\cup\bas_{\mathcal G}(B)$ otherwise, which is exactly the selector recursion. Conversely, an accessible
order is a \emph{basic word}, a left-parenthesized path term has the prefixes of its word as feasible sets, and same-root reset is pointwise
union, so joining the paths for all basic words realizes the antimatroid. Details are in \cref{app:proofs-reset}.
\end{idea}

\begin{remark}[Relationship with the older path normal form]
\label{reset:rem:priority}
For a constituent path $p$ using the whole support, the suffix criterion $E_p\subseteq E_t$ of Freese et al.\ says exactly that the reversal of $p$ is a basic word
of $\mathcal F_t$. Taking every such absorbed constituent therefore gives precisely all the antimatroid's basic words: this is their Lemma~3.5
normal form taken maximally \cite{FreeseEtAl2002}, and the basic-word presentation itself is not a separate normal-form theorem. The distinctions
studied here are the closure condition characterizing which constituent families occur, the compact polynomial guard tables and their algorithms,
and the substitution formula.
\end{remark}

\subsection{Algorithms, counting, and minimality}

The family representation can be exponentially large, but prerequisite antichains stay small. Given a candidate root $r$ and minimal antichains
$\mathcal G_j$, call a set $A$ \emph{constructible} if its positions can be ordered $a_1,\ldots,a_m$ such that for every $\ell$ some member of
$\mathcal G_{a_\ell}$ lies in $\{a_1,\ldots,a_{\ell-1}\}$. This is checked greedily: start empty and add any enabled member of $A$. Enabling is
monotone, so a greedy choice cannot prevent success.

\begin{theorem}[Exact realizability]\label{reset:thm:synthesis}
A table is the canonical table of a reset term exactly when:
\begin{enumerate}
\item $\mathcal G_r=\{\varnothing\}$ and no other antichain contains
$\varnothing$;
\item every member of $\mathcal G_j$ omits $j$;
\item every member of every antichain is constructible.
\end{enumerate}
Recognition is polynomial in the table description. A realizable
table with $M$ prerequisites on $n$ input positions has a term
realization of size $O(nM)$.
\end{theorem}

Constructibility has a simpler equivalent local form (proved in \cref{app:proofs-reset}):
\begin{equation}\label{reset:eq:complete}
 A\in\mathcal G_j,\ k\in A
 \quad\Longrightarrow\quad
 \exists B\in\mathcal G_k\; B\subseteq A.
\end{equation}
On actual support, the antichain, nonemptiness, self-exclusion, and completeness conditions are precisely the axioms for a \emph{dependency structure
with choice} (DSC) in \cite[Definition~2.9]{BazermanMinichielloPuzio2023}, whose correspondence with antimatroids is established there
\cite[Theorem~3.15]{BazermanMinichielloPuzio2023}. Thus the prerequisite model reuses DSCs, with one unconditionally enabled event, as a concrete
presentation of reset term functions. These are algorithms for formulas over the primitive reset operation. Its expansion into owned choices may
duplicate subterms, and no polynomial bound on that separate expansion is claimed.

Substitution is equally explicit. Let an outer table have root $r$ and prerequisites $\mathcal G_i$, and substitute inner tables with roots $r_i$ and
prerequisites $\mathcal H^i_j$. Inner ambiguity is determined exactly by the inner root, so
\begin{equation}\label{reset:eq:substitution}
 r_{\rm new}=r_r,\qquad
 \mathcal G^{\rm new}_j=
 \min\bigcup_i
 \left\{\{r_k:k\in A\}\cup C:
       A\in\mathcal G_i,\ C\in\mathcal H^i_j\right\},
\end{equation}
where $\min$ deletes nonminimal sets. This is polynomial in the two explicit table descriptions, and it respects actual term substitution, including mixed
inputs, rather than only a homogeneous observation.

Removing the unique initial element from every nonempty feasible set leaves an arbitrary antimatroid on the remaining support, and adjoining one initial
element reverses this. If $a_m$ counts labeled antimatroids on a full $m$-element support, with $a_0=1$, the number of $n$-ary reset term functions is
therefore
\[
 f_n=\sum_{m=1}^n\binom nm\,m\,a_{m-1}.
\]
Independent finite enumerations give
\[
 (a_0,\ldots,a_4)=(1,1,3,22,485),\qquad
 (f_1,\ldots,f_5)=(1,4,18,140,2980).
\]
The antimatroid counts are counts of known combinatorial objects; the equation describes their exact relationship to reset operations.

\begin{theorem}[Identification-minor minimality]\label{reset:thm:minimal}
Every nonprojection reset term has a binary identification minor equal
to reset. Hence its term clone is minimal.
\end{theorem}

Identify the root variable with $y$ and every other occurring variable with $x$: the prerequisite of $x$ can then only be $\{y\}$, and that is $x\del y$
(\cref{app:proofs-reset}). Minimality is already known for $G_3$ and its dual in Waldhauser's work; the direct proof records the stronger explicit recovery by
input identification, using the prerequisite representation. So there are no intermediate nontrivial subclones of the reset clone, though this
does not classify clones between reset and the larger owned-choice clone.

The conservative models of reset are exactly forest orders, and comb-shaped forests give explicit subdirectly irreducible models of every infinite cardinality;
\cref{app:reset-models} develops this, together with the known residual largeness of the variety \cite{FreeseEtAl2002}.
