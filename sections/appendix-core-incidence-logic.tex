\begin{theorem}[No monadic second-order incidence test]
\label{core:thm:no-cmso-incidence}
Fix $K\ge3$. Core realization is not definable by a fixed counting
monadic second-order sentence on the unordered incidence graph of the
two complete canonical lists, even with quantification over sets of
incidence edges. This holds with at most four minimal zeros per head.
More generally, even given a path decomposition of the incidence graph
as a stream of bag operations, no deterministic recognition algorithm
uses space $O(\log N)+f(b)$ for any fixed elementary $f$, where $b$
is the width and $N$ includes the supplied decomposition.
\end{theorem}
\begin{proof}
Use a typed graph with vertices for inputs, owners, lists, entries and
postings, and labeled incidence edges recording the head, observer,
membership and input--owner data. Postings may be identified by their
input and owner, or have separate occurrence vertices. Counting tests
use fixed moduli. Edge sets range over the displayed incidences.
We use path decompositions whose widths may increase with the input.

\emph{Evaluation on a supplied path.}
Write $T_0(x)=x$, $T_{j+1}(x)=2^{T_j(x)}$. For a fixed sentence
there is a fixed $h$ such that a stream introducing and forgetting
vertices in $b$ bag slots and inserting incidences can be evaluated in
space $T_h((b+1)^{O(1)})$. Here is the uniform dependence needed
beyond the fixed-width logspace theorem \cite{ElberfeldJakobyTantau2010}.
Represent each edge by a temporary typed element incident to its two
endpoints while both are present. A proposed vertex or edge set is
one membership bit at each introduction; individuals use singleton
sets. For annotated introductions, atomic relations and membership
are checked by remembering the annotations in the occupied slots,
recording the labeled incidences and singleton tests requested by the
formula. Cardinalities modulo a fixed integer need one residue each.
Projection of an annotation and determinization handle a set
quantifier; complement handles negation. Building the successive
finite transition tables, starting with the annotated slot alphabet,
costs at most the stated fixed-height tower. Only the current automaton
state is needed while scanning. If a transducer emits the slot stream
from a length-$n$ input in logarithmic space, its $O(\log n)$
workspace is added to the automaton bound.

\emph{A narrow quantified formula.}
Take a language in deterministic space
$O(\log n\,\log^*n)$ outside logarithmic space, by the space hierarchy
theorem \cite{StearnsHartmanisLewis1965}. A configuration of its
decider has $s=O(\log n\,\log^*n)$ bits. Use a single accepting
configuration and permit idle steps. Reachability within $2^{O(s)}$
steps has a polynomial-size quantified Boolean formula with
$O(\log^*n)$ quantifier blocks. At each level existentially give a
chain of $q$ subsegments with the required first and last endpoints,
where $q=2^{\lceil\log_2 n\rceil}$. Universally choose a segment by
its index and require its endpoints at the next level. After
$O(s/\log q)$ levels test one transition or equality. The endpoint
multiplexers and the final transition test have polynomial-size
circuits; existential gate bits give their CNF at the end. Counters
for the level, segment, tape position and bit suffice to print the
formula in logarithmic space.

Call a matrix $w$-leveled when its variables are partitioned into
groups of at most $w$ and its clauses into consecutive blocks, with
block $i$ using only groups $i,i+1$. Initially use one group. We
record the uniformity and prefix cost of the occurrence splitting of
Atserias and Oliva \cite[Lemma~2]{AtseriasOliva2014}. Replace each
variable by one bit per literal occurrence in its original quantifier
block. An inconsistent universal choice wins for the existential
player; otherwise the copied clauses must hold and the existential
copies must be consistent. This preserves truth: a strategy can
answer consistent previous moves as before, and a winning strategy
on consistent universal moves must keep its own copies consistent.

Here is a local verifier with three appended blocks. Existentially
choose the mode (exhibit a universal inconsistency or verify the
clauses) and one universal-variable rank per old group. Universally
choose one existential-variable rank per old group. Existentially
give a reference value for each of the latter ranks and the verifier's
work bits. In the first mode some selected universal rank must occur
with both values. In the second, every selected existential rank must
agree with its reference at all its occurrences, and every clause
must hold. Ranks designate positions in a group; absent ranks impose
no test. Universal choice of the existential ranks checks consistency
for every existential variable.

Scan literals in clause-block order. Only two old groups are active.
Place the quantified rank bits and reference at the start of each
group's active interval and propagate them by equalities between
successive records. Keep two flags for which values of the selected
universal have occurred in each active group, a running disjunction
of witnessed inconsistencies, the mode, and flags for the current
clause and the tests already completed. Each record compares its
known within-group rank with the propagated binary rank. Local
two-input gates and their CNF clauses use $O(\log(w+2))$ bits per
record and reference only consecutive records. The new variable
groups are the records. The scan and its groups are printed by
indices, retrieving a literal's group and within-group rank by
rescanning the previous lists in logarithmic space. Iterate a
\emph{fixed} number $J$ of times. Composition of these transducers
is logspace and the output size is polynomial. Its group width
is $w=O(\log^{(J)} n)$ and it has $a=O(\log^* n+J)$ quantifier
blocks, where $\log^{(J)}$ denotes iterated logarithm.

\emph{The guard incidence path.}
In \cref{core:thm:two-color-pspace,core:thm:complete-guard-pspace},
order variables in each quantifier block by matrix group. Use a binary
comb for the universal choice of a clause: at each split take the
next clause or continue to the next split. The game proof uses just
these two successors sharing a control label and the fact that control
edges join successive levels. It applies to this tree as well. Use
the literal tests of each clause in their listed order.

First consider the graph joining each marked input to the inputs
posted in its bare negative rows. Sweep the matrix levels in order.
Place variable gadgets at their groups and the clause comb, literal
tests and occurrence resources at their clause blocks. Within each
quantifier block the control chain visits variable groups in increasing
order. At a group boundary only constantly many control labels per
block cross on the chain. The connections from the end of one
quantifier block to the beginning of the next contribute another
$O(a)$ labels. Keep the constant-size variable gadget labels of the
current and adjacent groups throughout the local clause scan,
$O(w)$ labels in total. In particular the permanent label linking a
branch to its literal occurrences is available throughout all the
blocks where that variable occurs. The comb uses one continuing
branch at a time and each clause test is a path, requiring only
constantly many further active labels. The few input labels in the
two initial endpoint coalitions, including the padding input, can
be kept throughout. These intervals give width $O(w+a)$ and cover
all bare head--posting edges, including the endpoint-demand rows.

The selectors need constant size even for this logspace construction.
Color each of the constantly many padded endpoint labels individually.
Give the remaining permanent labels one color, the remaining literal
resource marks another, and the remaining control labels three colors
by the lower level of their edge modulo three. A control row marking
an edge at levels $l,l+1$ is at level $l+2$; its posted control
labels have lower level $l+1$ or $l+2$. A resource row posts its
permanent label, and the added endpoint rows post only the singled-out
labels. Thus no original head occurs in its own class's bare tails.
Use distinct constant-length selector codes for these classes as in
\cref{core:cor:source-feedback-hardness}. All colors and levels are
computable by indexed scans of the comb and variable gadgets.

To obtain the full incidence path, add all bare tail neighbors of
a head to every bag containing it. Each head has only constantly
many such neighbors by the three-posting construction and the two
padded endpoint rows. The increase in width is a constant factor;
every added neighbor's new interval meets its original interval
along the corresponding edge. At an ordinary head all its lists,
zeros, primes and posting incidences can now be emitted locally.
Keep the owners, selector inputs, their lists and their one large
zero per selector throughout. Emit the latter's postings and its
singleton-prime entries at each data input. Shared input--owner
postings require only $K$ copies of each active input. This gives
a path stream of polynomial length and width $b=O_K(w+a)$.
All lifetimes in the sweep are determined by group boundaries,
gadget positions and the indicated neighbor intervals. To rename
a bag by local slots, rank its active global indices by rescans;
permutations of occupied slots can equivalently be emitted as
relabeling instructions. This uses a constant number of logarithmic
counters, without storing the active bag.

A hypothetical additive-space algorithm now decides the hierarchy
language in space $O(\log n)+T_h((b+1)^{O(1)})$ for some fixed $h$,
since the combined encoding has polynomial length. A read-only
algorithm can revisit any position of the supplied stream by rerunning
its logspace transducer. The sentence evaluator is one such algorithm.
Choose the fixed $J>h+3$.
Then $T_h((\log^{(J)}n+\log^*n)^{O(1)})=o(\log n)$,
a contradiction.
\end{proof}

In particular, a condition phrased only on the prime lists is
excluded too: it could be applied to the prime part of the graph
with both lists supplied. The obstruction includes tests that select
a fixed number of sets of entries or incidence edges, use connectivity
on them, and count modulo fixed integers. The trees in
\cref{core:thm:prime-tree-cover} can introduce coalitions and
vertices beyond the listed entries.

The argument also allows an auxiliary linear order as a predicate
when the sentence must work for every supplied order and edge sets
still range over the displayed incidences. Supply the order of
first introduction in the stream. For two singleton annotations the
automaton can test their order as soon as both have appeared.
