\section{Dependent execution, full strategies, and disclosure}
\label{app:dependent}

The winner-set algebra deliberately observes finite public games. This
appendix states the dependent execution and disclosure interfaces that
retain information lost by that observation. It uses established
sum/product interpretations and a fixed-schedule noninterference argument;
no theorem below identifies hidden interaction with the public SPE algebra.
The closed complete-revelation fragment of \cref{sec:sealed-rounds}
has a separate quantitative SE semantics; its interface retains no
private cells across boundaries.

Consider the role-owned script
\begin{equation}
 \Q_A(n:\Nat_{>0}).\ \Q_B(v:\mathsf{Vec}(\Bool,n)).\
 \Q_C(j:\mathsf{Fin}(n)).\ G(n,v,j).
 \label{dep:eq:1}
\end{equation}
There is one supplied value at each binder, shared by all endpoints.
The owner-as-supplier and receivers-as-consumers interpretations are
instances of dependent multiparty session typing
\cite{ToninhoYoshida2017,WuXi2018,ToninhoCairesPfenning2011}.
