\paragraph{Several absorbing owners with bounded projections.}
For bounds $t(w^h)\subseteq U_h$, write
$P_h=\{i:w_i^h\subseteq U_h\}$ and $E_r^h=\{i:w_i^h=\{r\}\}$.
Suppose
$E_r^h\subseteq\bigcap_k P_k$ whenever $r\in U_h$.
Thus every input that can supply an allowed atom at one row
is bounded at every row. With this hypothesis, simultaneous
feasibility of either query has a direct common-input test.

For one requested winning coalition $A_s$ at each owner $s\in J$,
put $D=\bigcap_{s\in J}A_s$ and
$D_r=\bigcap_{s\in J\setminus\{r\}}A_s$, with the whole input
set as the empty intersection. The criterion is
\[
 D\ \cap\!
 \bigcap_{h:\ \forall r\in U_h,\ E_r^h\cap D_r=\varnothing}
 P_h\ne\varnothing.
\]
For a signed pair at $q$, use $D=A\setminus B$ and
intersect $D$ with $P_h$ for exactly the rows where
neither of the following holds:
\[
 q\in U_h\ \text{and}\ E_q^h\setminus B\ne\varnothing,
 \qquad
 E_r^h\cap A\ne\varnothing\ \text{for some }r\in U_h\setminus\{q\}.
\]

Necessity holds for arbitrary bounds. Follow one child meeting the whole query at
each gate. The positive rainbow passes to such a child
because only the gate owner's test is disjunctive. For a
signed pair exactly one of the two requirements can require
a choice of child. The resulting leaf lies in $D$.
If a row first ceases to be bounded along this path at
an $r$-gate, its sibling must be an allowed $r$-atom at
that row. For a rainbow the sibling also wins all foreign
requests, so the common-source condition gives an input
in $E_r^h\cap D_r$. For a signed pair at $r$ the sibling
loses $B$, giving an input in $E_r^h\setminus B$ by
monotonicity. For a signed pair at a different owner
the sibling wins $A$, giving an input in $E_r^h\cap A$
by the common-source condition. This proves both common-input
conditions.

For sufficiency it is enough that, for the query in question,
each row having an eligible absorber has one whose projection
is bounded at every row. Start with a projection in the displayed
intersection for the chosen query. For each row where
that projection is unbounded, attach a projection from the
corresponding eligible absorbing set at its owner gate.
This preserves the query by the singleton-profile recursion
and makes the output bounded at that row. Each attached
projection is bounded on every row by hypothesis, so
all previously established bounds persist. This yields one
witness with at most one attachment per row. The top bits
and the same two query forms again characterize the full
profile tables, by \cref{core:thm:profile-relations}.

For a single bound the hypothesis always holds. The test then
asks for a projection in $D\cap P_1$, or for $D$ to be nonempty
and the row to have an eligible absorber. In the latter case
one owned choice on two projections witnesses the query.

\paragraph{Several bounds on a spine of projections.}
A spine of projections starts with an input and
attaches one input at each owned gate. For this
fragment, arbitrary explicit output bounds and
signed singleton tests admit an exact reverse
test, without the bounded-projection hypothesis.

At a row with current allowed set $U$, let $v$
be the value of the attached input and $r$ the
gate owner. Take the preimage of the bound under
the attachment. If $U=I$, there is no restriction.
Otherwise the preimage has the following form.
\[
\begin{array}{c|c}
 \text{Condition} & \text{Allowed set before the attachment}\\
 \hline
 v=\{r\},\ r\in U & I\\
 v=\{r\},\ r\notin U & \text{infeasible}\\
 v\ne\{r\},\ v\subseteq U & U\\
 v\ne\{r\},\ v\nsubseteq U,\ r\in U & \{r\}\\
 v\ne\{r\},\ v\nsubseteq U,\ r\notin U & \text{infeasible}
\end{array}
\]
Indeed an incoming $r$-atom always absorbs.
In all other cases outside the first two lines,
the output is the union with $v$. In particular
an unsafe projection at an allowed owner's gate
can force the prefix to have that owner's atom.

For a signed profile test, take the preimage of
the specified Boolean value under OR if the gate
owns the test and under AND otherwise. The other
argument is one exactly when the attached input
lies in the tested coalition. The preimage is the
same sign, no restriction, or infeasible. Thus a
reverse sequence succeeds exactly when a common
starting projection meets all its residual rows
and signs. Reversing the chosen sequence builds
the witness directly.

In a successful sequence each output bound can
tighten at most once, to a singleton, and can
be released at most once. A singleton bound
cannot tighten further, and a released bound
stays unrestricted. Each signed test can change
only by being released. Delete an attachment
that changes none of the residual constraints.
Consequently with $m$ output bounds and $d$ signs
a witness, if one exists, uses at most $2m+d$
attachments. This gives an NP test from explicit
rows and signs for the fragment. The reverse
test tracks bounds on a single accumulating word.
The corresponding question for arbitrary terms
also allows a nonprojection helper at each gate.

\paragraph{Depth for explicit rows.}
The reverse calculation also bounds the depth of a
shortest unrestricted witness. Fix a root-to-leaf
path and use the value of each entire sibling in
place of the attached projection's value. The same
preimage table applies. A shortest witness has no
attachment along this path that leaves all residual
constraints unchanged: replacing that gate by its
path child would preserve the constraints at the
root and strictly reduce the tree. Thus the depth
bound $2m+d$ holds for arbitrary core trees with the
same $m$ upper bounds and $d$ signed tests.

Positive winner requirements at explicit valuations
can be included as well. For a requirement to retain
$k$, an attachment whose sibling is the gate owner's
atom makes the preimage either unrestricted or
infeasible. For any other sibling value $v$, the
preimage is unchanged if $k\notin v$. When $k\in v$
it is unrestricted at a $k$-gate and forbids just the
$r$-atom at a foreign $r$-gate. This last constraint
is a negative singleton test at the row's $r$-block
and can only be released or become infeasible.
Consequently $\ell$ positive winner requirements
increase the depth bound to $2m+d+2\ell$.

The bound counts explicit constraints even when the number
of inputs or owners varies. A succinct prime budget may
describe exponentially many such rows.

\paragraph{Splitting explicit constraints at the root.}
There is an exact finite recursion on residual constraints
with no need to enumerate child output tables. For each
possible root owner $r$, split each requirement between
its two children independently.
\begin{enumerate}
\item For an output bound $U$, require both children to
stay below $U$, or, if $r\in U$, give one child the
bound $\{r\}$ and leave the other unrestricted.
\item For a signed singleton test, use the OR or AND
recursion at that gate. A disjunctive requirement is
given to one child and a conjunctive requirement to both.
\item For a required winner $k$, give one child the
winner requirement. If $r\ne k$, give the other child
the requirement to omit the $r$-atom at that valuation.
\end{enumerate}
The first split separates absorption from union. In the
third, the child retaining $k$ already cannot be a foreign
$r$-atom. Thus the listed splits are sufficient and every
satisfying gate admits one of them. A leaf is accepted
exactly when one projection satisfies all residual
constraints. A positive $r$-atom constraint at a valuation
is just an upper bound by $\{r\}$, since values are
nonempty. Its negation is a negative singleton test.

Each original bound slot can hold its original constraint,
one of at most $K$ singleton bounds, or no constraint.
A sign can be kept or released. A winner slot can hold
its original requirement, a negative singleton test at
one of the other owners on that row, or no constraint.
Along a child edge, constraints keep their slot or move
from an original bound or winner requirement to one of
its new forms, and then may be released. A split with a
child state identical to its parent is unnecessary for
feasibility, because a witness for that child already
witnesses the parent state. The remaining splits can be
tested by a table ordered by the residual stages.
Its size is at most $(K+2)^{m+\ell}2^d$, and each
state has at most $K3^m2^{d+\ell}$ split trials.
This yields polynomial space by recursive search,
or time $(O(K))^{m+\ell}O(1)^d$ times a polynomial
in the explicitly supplied input using the table.

\paragraph{Packing source losses into explicit bounds.}
Group explicitly supplied minimal source losses with
the same observer $k$ and passive posting $t$ into
one set $A$ of losing heads. Source reconstruction
says that one valuation $v$ enforces the whole group
by omitting $k$ if its passive $k$-pattern is $t$
and the inputs containing $k$ are exactly $A$.
Such a valuation always exists: use the prescribed
atoms, and on each unposted input use
$I\setminus\{k\}$ with $k$ added just on $A$.

One bound can pack several such groups, at most one
per observer. Write $E$ for their set of observers,
with group $(t_k,A_k)$ at $k$. The following
conditions decide exactly when one valuation has
the required passive patterns and source sets.
\begin{itemize}
\item For each owner seen by an observer, all observing
groups prescribe the same atomic block for that owner.
These prescribed blocks must be pairwise disjoint.
\item At an input in an atomic block of owner $r$,
its set of memberships among the $A_k$ must be
$\{r\}\cap E$.
\item If $|E|\ge2$, every owner has a prescribed atomic
block. At an input outside their union, the set of
its observed memberships together with $I\setminus E$
must have size at least two.
\end{itemize}
Indeed with two or more observers each atomic block
is forced by a foreign observer. Outside the blocks,
the menu must be ambiguous and have precisely the
specified observed memberships. Adding all unobserved
owners attains the largest such menu and gives the
last test. The one-observer construction above covers
the remaining case. For a passing packing, the
single bound $v\mapsto I\setminus E$ is equivalent
to all its source losses, since each omitted observer
tests exactly the corresponding group's sources.

Thus the relevant row count for explicit feasibility
can be the number of packed groups of colorings,
independent of how many heads share each coloring.
For fixed $K$, a packing of size at most $m$ can be
found or ruled out in time exponential in $m$ times
a polynomial in the explicit loss lists. More than
$Km$ groups rule it out immediately. Otherwise
enumerate the compatible subsets of the groups and
use a subset table for their covers. Overlaps do not
affect the test, since repeated loss constraints are
idempotent. Combine with the root-split recursion
for an exact bounded-word test at this row count.

\paragraph{Fixed palette and few explicit bounds.}
For fixed $K$ and $m$, feasibility under $m$ explicit
output bounds is polynomial-time even with arbitrarily
many explicit signed profile tests and positive winner
requirements. The depth bound alone depends on the
number of requests. To avoid that dependence, use the
profile relation of the bounded terms, which is closed
under the mixed owner gates.

First check that the bounded relation is nonempty.
At each owner, keep the listed coalitions and the full
coalition. For every pair from this list determine
whether the first test implies the second in all bounded
terms, by testing one positive and one negative sign.
Close the listed positives and the full coalition under
these implications. Reject if the closure meets a listed
negative. Also test all choices of one closed positive
coalition per owner jointly against the bounds. Each of
these tests uses at most $K$ signs. If they all succeed,
the profile-relation theorem
(\cref{core:thm:profile-relations}) gives a bounded
term with the requested signs: on the listed coordinates,
the closure satisfies all forced bits, same-owner
implications and rainbow exclusions. Testing one test
per owner suffices because the full coalitions pad any
smaller selection.

Every subquery so far uses at most $K$ signs and
$m$ rows. The residual table decides each in time
exponential in $m$ times a polynomial in the input,
with degree depending only on the fixed palette. To check
positive winners, use the greatest bounded word under
the signed requests, described below. At a requested
valuation, test whether any demanded owner's singleton
is forced there by the positive requests. For each such
owner, rerun the signed procedure with the original
positives and that one singleton forbidden. If a singleton
is forced, it determines the greatest word's value.
Otherwise its value is the greatest word under the
bounds alone, and the requested winner there can be
tested with a single positive winner requirement and
no signs. All positive requests can be checked this
way, because their witnesses lie below the same greatest
word.

The palette restriction matters even without output
bounds. With an unbounded palette, positive profile
feasibility alone is coNP-complete. A certificate of
failure is a rainbow selection with empty intersection,
by the profile classification
(\cref{core:thm:profiles}). For hardness, use one owner
per variable of a CNF formula and one input per clause.
At each owner request two coalitions, each consisting
of the clauses not satisfied by one of that variable's
two assignments alone. A rainbow selection over every
variable has empty intersection exactly when the
selected assignment satisfies all clauses. Partial
selections can be padded by choosing values for the
remaining variables. Thus all requested profiles are
jointly feasible exactly when the CNF is unsatisfiable.

\paragraph{Greatest bounded operation under profile demands.}
Fix any source bound admitting a nonempty bounded
word, and let $G$ be its greatest core minorant.
Prescribe jointly feasible positive singleton tests
at some owners. Their bounded witnesses are closed
under union because a positive singleton test is
preserved by union of two winning words. Let $P$
be the union of all such witnesses. At each owner
its profile records exactly the tests forced by the
demands and the bound.

For a fixed owner $r$, the forced tests depend only
on the positive demands at $r$. Indeed, take any
bounded word passing those demands but failing the
test in question. Starting from it, attach a joint
positive witness once at each other demanded owner
$s$, using $\star_s$. Each attachment restores the
positive tests at $s$ by disjunction and preserves
all previously satisfied tests at other owners by
conjunction. At $r$ the failed test stays false.
The resulting word is bounded and meets all the
positive demands. This proves the ownerwise rule
even for an owner with no positive demand.

The greatest word under the positive demands has
the value rule
\[
 H(v)=
 \begin{cases}
   \{r\},&\text{a forced test at a demanded owner $r$
                  wins on its atomic block of $v$},\\
   G(v),&\text{no such test wins}.
 \end{cases}
\]
The winning owner is unique because its singleton
is the value of $P$. To obtain this rule, start at
$G$ and attach $P$ once at each demanded owner.
Where $P$ has a singleton at a demanded owner,
its attachment absorbs, and every later attachment
preserves it. Elsewhere no attachment changes $G(v)$,
since $P(v)\subseteq G(v)$ and does not supply a
triggering singleton. This operation is bounded and
passes the demands. It is greatest because any
witness is below $G$ and must give the forced
singletons. In particular it equals $P$.

Additional negative singleton demands are feasible
precisely when this greatest word passes them.
A negative at $r$ cannot hold in a word below a
value $\{r\}$, and the greatest word itself
witnesses feasibility if it passes every negative.
Thus feasible negative demands leave the greatest
word unchanged. For jointly attainable complete
profiles, take all their positive and negative
tests. The forced profiles at the prescribed owners
are exactly the prescribed ones, giving the same
value rule with the specified profiles in place
of the forced tests.

On a sole-source probe, the source guard for $H$
is the guard predicate for $G$ conjoined with
failure of the prescribed singleton tests on the
passive posting blocks. The marked head has a
full menu in this probe, so it adds no atomic
posting. In particular, if the profiles are
attainable, a desired source mark is feasible with
them exactly when it is feasible without them
and every prescribed test loses at the probe.
This applies to multiple positive marks using the
same $H$. For a direct prime-list rule, fix a head $i$ and
observer $k$. For each prescribed owner $r\ne k$,
keep its minimal winning coalitions that omit $i$.
The discarded coalitions cannot be fully posted
on a probe at $i$. Take the minimal transversals
of the kept coalitions, as exclusions at $r$.
If no coalition remains, the empty transversal
gives the unconditional guard. These are precisely
the primes that keep the $r$-test losing, since
every posting of a kept coalition is permitted
on the facet and its exclusions must hit it.
The primes of $H$ on this facet are the
inclusion-minimal unions of one prime of $G$
and one such transversal at each prescribed
visible owner. A sufficient guard for the
conjunction must be sufficient for each factor
on the same facet and therefore contain a prime
from each. Conversely every listed union
suffices, which proves canonicity.

This transformation includes arbitrary hypergraph
transversal enumeration even for an unrestricted
bound equal to full union, whose primes are empty
guards. Prescribe one owner $r$ and use the
nonempty edges of an arbitrary nonempty
hypergraph, minimized by containment, as its
minimal winning coalitions. The profile is
attainable by taking a foreign owned fold on
each edge and combining the folds at $r$.
Add a fresh head outside all edges. On any
foreign facet at that head, the masked primes
are exactly the hypergraph's minimal transversals
as $r$-exclusions. In particular $m$ disjoint
two-element winners give $2^m$ primes there.
Thus small minimal-winning lists alone do not
bound the size of the canonical masked lists.

Verifying a proposed complete masked list on one
facet is polynomial-time many-one equivalent to
hypergraph duality, the decision whether a proposed
list contains exactly the minimal transversals of
a given hypergraph. The full-union example gives
one direction. For the other, collect the
visible minimal winners as hyperedges of
postings. A set of exclusions is sufficient
exactly when it hits all these edges and
contains a prime of $G$. Check every proposed
prime for sufficiency and test that removing
any one exclusion destroys sufficiency.

For completeness, fix a prime $g$ of $G$ and
test guards containing $g$. Drop the mask
edges already hit by $g$. From every proposed
prime delete its exclusions in $g$, and
minimize the resulting list by containment.
It describes exactly the residual exclusions
that already contain a proposed prime after
adjoining $g$. Every residual list member
hits every remaining mask edge, because
the original proposed prime did and the
remaining edges avoid $g$. Thus this list
covers all sufficient extensions of $g$ if
and only if it is the minimal-transversal
list of the remaining edges. This gives one
duality instance per prime $g$, using only the
supplied lists.

Combine all these instances into a single one.
Index their monotone CNFs and proposed DNFs by
$j$, and introduce a fresh selector $t_j$ per
instance. Add $t_j$ to every clause of CNF $j$,
and require $t_i\lor t_j$ for each distinct pair
of selectors. On the DNF side include the term
containing all selectors. For each term of DNF
$j$, include that term with every selector
except $t_j$ adjoined. If all selectors are
true both formulas hold. If just $t_j$ is
false, the two formulas restrict to instance
$j$. With at least two false selectors both
formulas fail. Thus the combined formulas are
equivalent exactly when all residual instances
have complete lists. Minimize the combined DNF
by containment. If a remaining term is not a
minimal transversal of the combined clauses,
equivalence already fails and one can return
a fixed negative duality instance. Otherwise
the combined clauses and minimized DNF are
the requested hypergraph and proposed dual.
A facet with no prime of $G$ has an empty
masked list and can be checked separately.

Restriction to a scope transfers the profile mask
to positive demands on that scope. Let $A$ be the
scope, and let $\phi_r$ be the profile used to mask
$G$ at a prescribed owner $r$. A word on $A$ is
bounded by the masked operation exactly when it
is bounded by $G$ and satisfies every positive test
of
\[
        E\longmapsto \phi_r(E\cup(V\setminus A))
        \qquad(E\subseteq A)
\]
at every prescribed owner. For necessity extend
a local valuation by posting every omitted input
at $r$. If the displayed test wins, the masked
bound is $\{r\}$ on this extension. A nonempty
word on $A$ must therefore give $\{r\}$ at
the local valuation. Conversely, whenever a
global valuation triggers the mask at $r$,
monotonicity makes the transferred test win at
its local $r$-block. The word gives that singleton.
At other valuations its bound by $G$ suffices.

On minimal-winning lists this transfer intersects
each winner with $A$ and then minimizes. An empty
intersection forces a win on the empty coalition
and rules out every nonempty scoped word. Even
when all transferred winners are nonempty, their
joint demands may fail. For distinct $r,s$,
take profiles requiring respectively $\{x,z\}$
and $\{y,z\}$, with full unanimity at the other
owners. They are jointly attainable under full
union by common source. On the scope $\{x,y\}$
their transferred demands require an $r$-win on
$\{x\}$ and an $s$-win on $\{y\}$, which have no
common source. Thus the scoped masked operation
has no nonempty core minorant. When the transferred
demands are feasible, their greatest envelope is
computed under the unmasked scoped bound by the
positive-demand rule above.

For a mask over full union, this gives a support
characterization without any residual recognition
test. Form the hypergraph of intersections obtained
by choosing one minimal winner from each prescribed
owner. If none is prescribed, use $V$ as its single
edge. A nonempty bounded word exists on scope $A$
exactly when $A$ meets every edge. Indeed the
transferred winning coalitions have all their
rainbow intersections nonempty exactly under this
condition. Their monotone profiles are then
compatible by the common-source theorem, filling
unprescribed owners with unanimity on $A$.
The greatest scoped word is full union on $A$
masked by the transferred profiles themselves.

For a mark at head $i$ under proper passive
coloring $p$, add the edge $\{i\}$ and, for every
original minimal winner $C$ of each prescribed
owner $r$, add the edge $C\setminus p_r$.
The scopes supporting the mark are precisely
the transversals of this enlarged hypergraph.
Indeed the head must be included, and the
transferred $r$-test must lose on the scope's
$r$-block. This says exactly that the scope
meets $C\setminus p_r$ for every $C$.
When these conditions hold, the scoped greatest
completion supplies the mark. For several
positive probes add their edges together:
the same completion supplies all of them.
Thus inclusion-minimal witness scopes are
the minimal transversals, and weighted minimum
scope is exactly weighted hitting set on these
explicit edges at fixed $K$.

The transfer also applies to arbitrary core
substitutions $g_j$, even when their supports
overlap. For each original minimal winner $C$
at $r$, prescribe a quotient win at $r$ on
\[
                     \{j:\Phi_r(g_j)(C)=1\}.
\]
A quotient word lifted through the $g_j$ is
bounded by the masked operation exactly when
its lift is bounded by $G$ and the word passes
all these transferred demands.

For necessity give singleton $r$ to the original
inputs of $C$ and the full menu to all others.
The quotient's $r$-atomic block is exactly the
displayed set, by the singleton laws for the
$g_j$. Its lift is forced to be singleton $r$
there by the mask. Conversely, on any valuation
triggering the mask through $C$, the actual
quotient $r$-block contains the displayed set
by monotonicity of the substituted profiles.
The quotient word therefore supplies the required
singleton. For unions of partition parts, the
displayed set is exactly the parts wholly
contained in $C$.

The unmasked source bound also transfers through
arbitrary core substitutions. Take a sole-source
probe for each original minimal loss on each
observer facet. Evaluate the $g_j$ there and
record their singleton statuses as a quotient
coloring. At every quotient port carrying the
observed winner, impose a loss on that port
with the other ports' recorded statuses.
Source reconstruction says that the quotient
omits the observed winner exactly when it
omits all these source marks. No port can
be singleton at the observer on this probe:
no original input is singleton at that owner,
and its empty singleton test loses for every
core word. The projected constraints are
therefore proper source losses.

This transfer is exact because the lifted word
is core, so the original minimal loss probes
test its entire upper bound. Likewise, an
original positive probe asks for at least one
of the corresponding quotient marks to survive.
The substituted words may share inputs and
several ports may carry the same mark. With
explicit losses the quotient budget has at
most one row per port and original loss probe.
Together with the transferred positive profiles,
it reduces the greatest masked lift to a
greatest bounded operation on the quotient
ports. For unions of disjoint parts only the
original head's part carries the mark, giving
the whole-part loss projection.

For a direct projected-loss test from prime lists,
fix a quotient head and an allowed alphabet of
quotient postings. Seek an original loss probe
whose selected quotient port carries the observed
winner and whose other ports' singleton statuses
all lie in the allowed alphabet. One may use any
original loss for this test: including probes
above minimal losses preserves exactness, because
a bounded lift already omits all original losses.

Choose the original head, observer, and one
enabled prime for its mark in the selected
substituted operation. Use one Boolean variable
per allowed original posting, with consistency
clauses forbidding competing postings. Require
every prime of the original bound at this head
and observer to be hit. The chosen carrier prime
adds absence units. For each forbidden quotient
posting $j:s$, require the singleton predicate
$\Phi_s(g_j)$ to lose on the original $s$-block.
Using minimal winners of that predicate, forbid
the full posting of each such winner. These
constraints characterize projected-loss existence:
a satisfying assignment is exactly an original
loss whose projected statuses are allowed and
whose selected port carries the mark.

If the original prime width is at most two
and every substituted singleton profile has
minimal winners of size at most two, the
formula is $2$SAT for each choice of carrier
prime. This includes overlapping substitutions
by two-input owned folds or unions. The test
does not need to enumerate original losses
or require the quotient itself to have small
prime width.

If all quotient heads except one are retained,
the width-two test also synthesizes the quotient
bound by a polynomial-size core circuit. For each
choice of original head, observer and carrier prime,
keep the corresponding $2$SAT formula symbolic.
A prohibited quotient posting enables its negative
clauses exactly when that posting is absent on
the query. All other clauses are unconditional.
Thus each implication edge is unconditional or
is enabled by one quotient posting absence.

Use the implication-path filters for partition
quotients described in the block-activation
appendix. A labeled edge tests absence by
attaching the corresponding retained projection
at its owner. Union incoming paths at each vertex,
unrolling to the number of literals, to compute
reachability filters by a circuit. For each literal
compose the filters in the two opposite directions
to its negation and union over literals. This
tests unsatisfiability of the enabled constraints.
An enabled empty clause gives an additional
immediate unsatisfiability test. Compose the
unsatisfiability filters across the carrier
choices. A head mark survives exactly when no
projected loss is contained in the query.
Applying this filter to the head projection and
adjoining the retained projections gives the
greatest quotient, or zero if no projection
can be used. The argument only uses the
substituted singleton profiles and carrier
primes, so it also handles overlapping
substitutions.

With a source order on the projected budget, the same
constraints compute the greatest quotient's source
predicates by a polynomial-size monotone Boolean
circuit, with any number of conditional heads.
Use posting absences of the proper query as the
external bits. In source order, forbid a quotient
posting if its input is already active and the
posting is absent in the query. These forbidden
bits enable the corresponding binary constraints.
Test that every carrier instance is unsatisfiable
using reachability in its implication graph.
The result is the activation bit for this head.
This is exactly the ordered marked-source test
of \cref{core:thm:acyclic-marked-source-test}:
every projected loss must meet an already active
mismatching posting. Its graph computations can
all be unrolled as monotone Boolean reachability
circuits, since edges become available when more
forbidden bits are set. No projected primes are
needed.

Consequently, for a specified family of core
substitutions satisfying the binary hypotheses,
exact realization of the original candidate by
a quotient lies in coNP when the projected
budget has a source order. The greatest
quotient lifts below the candidate by construction.
A failure of equality specifies an original
positive sole-source probe. Evaluate the
substitutions there, test the activation bits
at the carrying ports, and check that all
those bits fail. This evaluates the greatest
lift on the probe in polynomial time, given
the substitutions as core circuits and the
required singleton-profile lists.

This coNP test needs no supplied source order if
acyclicity is part of the acceptance condition.
A dependency edge can be certified by a projected
losing coloring that becomes positive on deleting
the relevant posting. One direction takes a
minimal projected loss containing the posting.
Conversely, every minimal loss inside a certified
coloring must contain that posting. Both coloring
tests use the binary loss oracle. Thus a cycle in
the exact dependency graph has a polynomial
certificate, even with implicit quotient primes.

If the budget is acyclic but a required original
positive fails, give its probe and, for every
carrying port, an obstruction from the ordered
activation pass. For that port record one loss at
each inactive head needed in the obstruction,
such that postings outside the recorded heads
agree with the query. The recorded internal graph
is acyclic, and the marked port is among its
heads. The acyclic cut forbids the mark regardless
of whether the full projected graph is acyclic.
Thus the verifier only checks that the recorded
rows are losses, tests their internal acyclicity
and compares their boundary with the query.
Acyclicity of the full budget guarantees these
certificates exist for every failed carrying
port, by the inactive-head construction in
\cref{core:thm:acyclic-marked-source-test}.
Together with the separate cycle certificate,
this recognizes the acyclic exact quotients
in coNP directly from the supplied data.

A different polynomial coefficient test allows
cycles in the projected dependency graph. Suppose
every minimal projected loss has at most one
posting at each owner. Run singleton-block fold
saturation on the quotient, using the binary loss
oracle instead of explicit quotient primes.
At each step ask whether a loss avoids all
previously deleted postings and the postings of
the proposed fold support. The implication-graph
test for absence of a loss is monotone in the
excluded postings, so it also supplies the monotone
subcircuits for the saturation registers. The
singleton-block theorem gives exactness on this
class, independently of acyclicity.

The restriction can be part of a coNP acceptance
test for exact quotients. To certify its failure,
give a losing coloring with two distinct postings
at one owner such that deleting either posting
makes it positive. Then every minimal loss
contained in the coloring includes both postings.
Conversely a violating minimal loss supplies such
a certificate. Once the restriction holds,
a missed original positive is again a polynomial
certificate, now checked by fold saturation
on its projected query. This gives a second
coNP class of exact quotients with implicit
projected losses.

There is a deterministic equality test when the
original bound and every substituted operation
have losses at just one common posting owner $a$.
The projected budget uses only $a$: its original
loss probes have no singleton inputs at any other
owner, so none of the substituted outputs can
supply such a singleton. Its greatest quotient
is consequently the union of safe $a$-folds.
At a quotient query a port is available exactly
when it lies in the greatest safe support outside
the query's $a$-block. Compute that support
by pruning, with the binary projected-loss
test. Only the substituted $a$-profiles need
the bound of two on their minimal winner size
in this case.

On an original sole-source probe, each
substituted mark depends only on the original
$a$-block and is antitone in it. The quotient
$a$-block grows with the original block,
since the substituted $a$-profiles are monotone.
The lifted mark is therefore antitone in that
one block as well. For each original head and
prime on a foreign facet, test the largest
$a$-block that prime permits. On the $a$-facet
test the empty block. These worst-case tests
are sufficient for all original positives,
and the lift is already bounded by the
original candidate. This gives a polynomial
exact-quotient test under the binary hypotheses,
allowing arbitrary projected cycles and prime
width.

When the substituted operations are $a$-folds
on given supports, the equality test needs no
width bound and does not construct the quotient
loss oracle. Every bounded quotient can be
enlarged by replacing foreign gates by union,
since all projected losses are pure at $a$.
Distribute the $a$-gates over union. A quotient
$a$-fold lifts to the $a$-fold on the union of
its selected supports, including when the
supports overlap. Thus the greatest lift is
the union of safe original folds whose supports
are unions of supplied supports.

At a probe with $a$-block $E$, start with all
supplied supports disjoint from $E$. Take their
union $U$. If a head in $U$ has a loss missing
$U$, delete every remaining support containing
that head and repeat. No feasible union can
include such a head, since it would also miss
that loss. At stabilization the union is safe,
and it contains every feasible union avoiding
$E$. Therefore it gives exactly the available
sources at the probe. To check a loss missing
$U$, test the original primes on the largest
allowed pure $a$-block outside $U$.
The same worst-case checks per original prime
decide exact equality in polynomial time,
directly from the support lists and with
arbitrary original prime width.

The one-owner fold presentation has a canonical
irredundant support family. Include the empty
set among the safe supports. They are closed
under union, since adding safe supports cannot
destroy the witness hit of a loss at an included
head. A nonempty safe support $S$ is
join-irreducible exactly when there is a head
$i\in S$ in no proper safe subset of $S$.
Indeed, if every head lies in some proper
safe subset, the union of those subsets is
$S$. Every safe support is a union of
join-irreducibles by induction on its size.

The greatest minorant is the union of the
folds on these irreducible supports. If a
fold supplies a mark from $S$, a constituent
support containing that head supplies the same
mark. Conversely, for an irreducible support
choose its distinguished head $i$ and post
$V\setminus S$ at $a$ in a foreign source
probe. Any safe fold providing that mark
has support inside $S$ and contains $i$,
so its support must be $S$. Hence every
fold presentation needs that support.

This gives a direct prime-list characterization
in the one-owner class. For each foreign
prime at $i$, adjoining the head to its excluded
inputs must give a safe support, and this
condition suffices for core realizability.
Indeed its exclusions define the largest
permitted $a$-block. A safe fold supplying
that probe must have support contained in
the proposed support and containing $i$.
Any proper such support would give a smaller
sufficient guard, contradicting primality.
Conversely the fold on the proposed support
supplies the whole prime. The distinct
supports obtained this way are exactly the
irreducible ones. An exact expression through
supplied $a$-folds exists precisely when each
is also a union of supplied supports, which
can be checked by taking the union of all
supplied supports contained in it.

The projected prime width can be unbounded
even in this polynomial case. Fix owner $a$
and use retained pairs $t_j,f_j$ for $1\le j\le m$.
At the marked head let the original primes require
losses to post at least one member of each pair
at $a$, and additionally post $t_1$ and $f_m$
at $a$. These requirements are binary and unary
clauses on the loss postings. They give canonical
primes after minimization, and the one-source
completion realizes the bound. Use the projection
of the head and, for each $j<m$, a quotient port
that unions $t_j$ and $f_{j+1}$. Give unused inputs
their own ports if all inputs are to be covered.

On a foreign facet, exclude the $a$-posting
at each of these $m-1$ union ports. An original
loss compatible with the exclusions would have
to post $t_1$, then $t_2$ because $f_2$ is
forbidden, and inductively all the $t_j$.
This contradicts the forced $f_m$ on the last
binary exclusion. If any exclusion is removed,
posting the true inputs up to that gap and the
false inputs after it gives a compatible loss.
Thus the whole set of exclusions is a projected
prime of width $m-1$. Duplicating each union port
gives $2^{m-1}$ different primes by choosing
one of its two copies for each exclusion. Every
chosen exclusion still has the same private loss
when it is removed. This yields exponential
list size with overlapping binary substitutions.

The width-two restrictions are sharp for this
projected-loss decision problem. It is NP-complete
if either width bound is raised to three, even for
a one-head core bound at a fixed palette and
substitutions by unions of at most three inputs.
Use a retained input for each of the two signed
literals of every Boolean variable, and a fresh
head carried by its own projection. Fix an owner
$a$. At the original head use a prime excluding
the two $a$-postings of each variable pair.
Thus an original loss must post at least one of
each pair. Forbid singleton $a$ at the quotient
union of each pair, ensuring it posts at most
one. All guards use the same color and are
canonical after minimization. The bound is
core by one-head completion.

To keep the original width at two, add a quotient
union for each clause, on the inputs for the
negations of the literals in that clause. Forbid
singleton $a$ at that union. A projected loss
now corresponds exactly to a truth assignment
with no fully falsified clause. The triple
unions have a minimal winner of size three.
Alternatively, keep all quotient unions binary
and place the clauses instead in the original
prime list, excluding the $a$-postings of their
satisfying literals. An original loss must hit
each such prime, and the quotient pair tests
still enforce consistency. In this version the
original width is at most three. In both
versions the original loss can be checked
directly as a polynomial-size certificate.

For a mask over full union the transferred
profiles are again sufficient when compatible.
Thus a partition admits a nonempty bounded
quotient exactly when every choice of one
original minimal winner per prescribed owner
has an intersection containing an entire part.
The greatest quotient is full union of the parts
with the transferred profiles imposed. A source
mark at a given probe also requires each
transferred test to lose there: for every
minimal winner $C$ at $r$, some part contained
in $C$ must fail to be posted entirely at $r$
on the probe. This is the part analogue of
the scoped hitting-set criterion.

Exact factorization of a mask over full union has a
simpler criterion: every prescribed minimal winner
must be a union of parts. For necessity, if a
quotient realizes the full operation, its lift must
pass all transferred tests. For an original minimal
winner $C$ at $r$, post the union of the parts
contained in $C$ at $r$ and leave all other inputs
ambiguous. The lift wins at $r$ by the transferred
test. Exactness and minimality of $C$ force this
union to equal $C$. Conversely, when every winner
is a union of parts, a transferred test wins
exactly when the original profile wins on the
lifted valuation. The transferred profiles are
compatible because every rainbow intersection
of original winners is a nonempty union of
parts. The quotient profile completion thus
has the same singleton masks, and otherwise
returns the union of all original inputs.

The coarsest exact partition groups inputs with
identical membership in all prescribed minimal
winners. It can be found directly from profile
CNFs, without listing their winners. To separate
$x$ from $y$, seek a minimal transversal of the
clauses containing $x$ but omitting $y$, or the
reverse. For the first direction try a private
clause containing $x$: delete its other inputs
and delete $y$, then test that every clause
still has an available input. A minimal
transversal in this alphabet must contain $x$.
Conversely a separating minimal winner has
such a private clause. Testing both directions
for each pair and each prescribed owner
determines the coarsest partition in polynomial
time.

\paragraph{Restricting the owners in a bounded query.}
For any collection of upper bounds, retain the owners
$s$ for which some row has $s\in U_h$ and $E_s^h\ne\varnothing$,
with $E_s^h=\{j:w_j^h=\{s\}\}$. If a positive rainbow or a
same-owner positive/negative pair has a witness, it has one
using gates of the retained owners alone.

To see this, prune each gate of an omitted owner to one child.
At a row where a subterm was bounded, such a gate cannot absorb:
an allowed singleton at its owner would have to originate in a
singleton input at that owner. Thus both children are bounded
at those rows. At a retained gate, any child originally
absorbing at a bounded row stays absorbing, since replacing
omitted gates by either child can only increase the singleton
profiles of retained owners. At all other bounded rows both
children were bounded. These facts let the induction pass
the requisite bounds to each child.

The query itself can be passed down at the same time. For
a rainbow, at a deleted gate select the child winning its
owner's request if one was made. Both children win the other
requests. For a same-owner signed pair, select a positive
child at a gate of the queried owner and a negative child
at any other gate. The opposite requirement holds in both
children. At retained gates distribute the requests using
the profile disjunction and conjunction, and keep both
children. This preserves the query through the pruning.

\paragraph{Simultaneous bounds with one permitted atomic absorber.}
Arbitrarily many non-atomic bounds have a closed joint test when the
allowed atomic absorptions have one common owner. The bounds themselves
need not be nested or have the same allowed set.

Fix finite $V$, an owner $r$, and bounds
$t(w^h)\subseteq U_h$, indexed by $h$. Put
\[
 P_h=\{j:w^h_j\subseteq U_h\},\qquad
 E_s^h=\{j:w^h_j=\{s\}\}.
\]
Assume
\begin{equation}\label{core:eq:single-absorber-budget}
 E_s^h=\varnothing\quad\text{whenever }s\in U_h\setminus\{r\}.
\end{equation}
An allowed singleton produced by any core term at any bounded row
can therefore only be $\{r\}$.
Let $d$ be the Horn closure on $V$ generated by
\[
 E_r^h\longrightarrow V\setminus P_h\quad(r\in U_h),
 \qquad
 \varnothing\longrightarrow V\setminus P_h\quad(r\notin U_h),
\]
and set $G(D)=V\setminus d(V\setminus D)$. The closure may have loops.

\begin{theorem}[Profiles under simultaneous budgets]
\label{core:thm:simultaneous-profile-budgets}
Let $K\geq3$ and assume \eqref{core:eq:single-absorber-budget}.
For one requested positive coalition $A_s$ at each owner $s\in J$,
there is a core term respecting every bound and satisfying every
request if and only if
\[
 G\biggl(\bigcap_{s\in J\setminus\{r\}}A_s\biggr)
 \cap\begin{cases}A_r,&r\in J,\\V,&r\notin J\end{cases}
 \ne\varnothing.
\]
For a pair $\Phi_q(A)=1$, $\Phi_q(B)=0$, simultaneous feasibility is
equivalent to
\[
 \begin{cases}
  G(V\setminus B)\cap A\ne\varnothing,&q=r,\\
  G(A)\setminus B\ne\varnothing,&q\ne r.
 \end{cases}
\]
Consequently a prescribed full table $(\phi_q)_q$ has a core realizer
respecting all the bounds exactly when:
\begin{enumerate}
\item $\phi_q(V)=1$ for every owner;
\item every pair with $\phi_q(A)=1$, $\phi_q(B)=0$ passes the displayed
  pair test;
\item every selection of winning coalitions $A_q$ for all owners satisfies
  \[
   G\biggl(\bigcap_{q\ne r}A_q\biggr)\cap A_r\ne\varnothing.
  \]
\end{enumerate}
\end{theorem}
\begin{proof}
For a nonempty support $S\subseteq V$, the $\star_r$-fold on $S$
respects row $h$ exactly when
\[
 S\subseteq P_h
 \quad\text{or}\quad
 r\in U_h\text{ and }S\cap E_r^h\ne\varnothing.
\]
Indeed an $r$-atomic input absorbs the fold; otherwise its value is the
union of the selected inputs. Complementing $S$ gives exactly the Horn
rules above. Thus $G(D)$ is the greatest safe fold support contained
in $D$.

The owner restriction above leaves only $r$-gates in a
witness to either query. Associativity and idempotence at
$r$ reduce this witness to a fold.

Such a fold has owner-$r$ profile $[S\cap A\ne\varnothing]$ and every
foreign profile $[S\subseteq A]$. Its support conditions give exactly
the two tests, since $G(D)$ is the greatest safe support in $D$.

Finally, the complete profile tables of all simultaneously bounded
terms form a relation closed under every mixed owner gate: combining
two values contained in $U_h$ stays in $U_h$. Apply
\cref{core:thm:profile-relations}. The pair tests account for all
same-owner implications, and the rainbow tests for all rainbow
conflicts. Top bits account for forced bits and extend partial
rainbows to all owners. The resulting table therefore belongs to
the bounded relation. This assembly can use all owners; the fold
normalization is required only for the individual queries.
\end{proof}

The closure incorporates genuine interactions between rows. For distinct
$a,b,c$, take $r=a$, both allowed sets $U_1=U_2=\{a,b\}$, and
\[
\begin{array}{c|ccc}
 &x&y&z\\\hline
 w^1&\{c\}&\{a\}&\{a,b\}\\
 w^2&\{a,b\}&\{c\}&\{a\}.
\end{array}
\]
The requests $\Phi_a(\{x\})=1$ and $\Phi_b(\{x,y\})=1$ are feasible
under either bound separately: $x\star_a y$ works for the first and
$x$ for the second. Jointly, the Horn rules are
$\{y\}\to\{x\}$ and $\{z\}\to\{y\}$. A support contained in
$\{x,y\}$ has $z$ in its complement; closure forces first $y$ and
then $x$ into the complement. Thus $G(\{x,y\})=\varnothing$, and
the joint rainbow test fails. The theorem uses one closure of all
budgets, rather than a conjunction of separate one-row tests.

For a fixed rainbow or signed pair, write the test as
$G(D)\cap M\ne\varnothing$. Failure needs at most $|D|$ rows.
Start the Horn derivation at $V\setminus D$ and record one row
for each newly added input until the closure contains $M$.
Keep just the recorded rows. In their original order the same
rules still derive those inputs, so the query still fails.
In particular, any full profile incompatible with the bounds
is ruled out by one query with at most $|V|$ rows, or by a
top-bit violation alone.

The row bound is sharp even for the empty rainbow. Take $n$
inputs and $n$ rows, each with allowed set $\{a,b\}$. At row
$j$ put $w_j^j=\{c\}$ and, if $j>1$, put
$w_{j-1}^j=\{a\}$. Give every other entry the value $\{a,b\}$.
The rules are $\varnothing\to\{1\}$ and
$\{j-1\}\to\{j\}$ for $2\le j\le n$. They force the
whole input set. If row $j$ is removed, the $a$-fold on
$\{j,\ldots,n\}$ meets every remaining bound. At earlier rows
all selected inputs are bounded, and at later rows the fold
absorbs to $\{a\}$.
