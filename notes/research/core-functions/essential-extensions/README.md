# Canonical essential-source extensions: research package

These research results have written proofs and independent finite checks.
They await Lean formalization and report integration, and do not count as
completion of the characterization of arbitrary canonical guards.

## The common definition

The four values are b,c,N,P. Inf is min in b<P<N<c; sup is max in b<N<P<c.
Observer union absorbs P, merges b,c to N, and otherwise retains N.
For a monotone nonconstant Boolean f, D_f fixes each partial-input subcube's
stable Boolean output when there is one. On a nonconstant cube it returns P
exactly when at least one P-marked free coordinate is essential for f on that
cube, and returns N otherwise.

## Established results

1. **Pure/full equivalence for the entire canonical family.** D_f has a
   full three-operation term realization iff it has a pure two-operation
   realization. Distribute full terms over union; stable Boolean outputs
   force every pure summand to have the same Boolean function f, and the
   essential-source lower bound plus P absorption force every summand to
   realize D_f itself. The argument is included in
   weighted-majority-counterexample.md.

2. **Exact graph-family criterion.** For f_G=∨_{ij∈E(G)}x_ix_j, with at least
   one edge, D_fG is realizable iff G is a cograph, equivalently induced-P4
   free. The cotree formula and its complete proof are in cograph-theorem.md; the
   self-contained P4 base proof is in p4-base-obstruction.md.

3. **Weighted majority does not suffice.** The exactly self-dual threshold
   (3,2,2,1,1;5), f=ab∨ac∨ade∨bcd∨bce, has a nonrealizable D extension.
   Five cofactor transfers give the proof. Therefore neither threshold
   functions nor read-once threshold composition characterizes this family.

4. **The hereditary SCC alternative is insufficient.** The six-variable
   F=cd∨af∨ace∨ade∨cef∨bdef passes that alternative on every cofactor, but
   D_F is nonterm. An eight-cofactor, two-Boolean-function descent certificate
   is given in six-variable-counterexample.md. Every proper cofactor has an
   explicit pure realization, checked independently over all B inputs.

The exact relative-budget synthesis reduction and safe-child preorder lemma
are recorded in relative-safety-game.md. They explain why the hereditary SCC
test loses information; they are not advertised as a short closed clone
characterization.

## Reproduce

    python3 check.py
    python3 check.py --exhaustive-cographs

The checker uses only the Python standard library and contains all necessary
truth functions, operation tables, marked-cube certificates, and cofactor
witness terms. The second command additionally checks all 471 nonempty-edge
labeled cographs on five vertices on all 4^5 inputs. The default checks through
four vertices, as well as both negative examples and all twelve positive
six-variable cofactor witnesses.

The source code and exploratory count data remain in the parent /tmp directory:
- df-safe-decomposition.py/json: exact arity4 canonical classification, 154 of
  166 nonconstant monotone functions; the other12 are P4 permutations.
- df-safe-five.py/cpp/dat and proof.txt: 4,075 positive five-variable canonical
  constructions, 2,724 functions with P4 restrictions, and780 additional root
  obstructions, partitioning all7,579 nonconstant monotone five-variable
  functions. The count data are not needed for any packaged theorem.
- df-relative-game.py and df-six-short-certificate.py: discovery and reduction
  of the six-variable obstruction. The package's checker independently checks
  the final finite certificate without trusting those search programs.

## Literature fit

The standard cograph/cotree equivalence is due to Corneil, Lerchs, and Stewart
Burlingham, [Complement reducible graphs](https://doi.org/10.1016/0166-218X(81)90013-5),
Discrete Applied Mathematics 3 (1981), 163–174. The Boolean read-once theorem
adds a normality condition to P4-freeness of the co-occurrence graph; it does
not imply the present graph D theorem (a triangle gives majority, which is not
read-once but whose canonical D extension is a pure term).

The inspected bichain literature concerns varieties and identity/word problems:
Harding–Walker–Walker, *The variety generated by the truth value algebra of
type-2 fuzzy sets* (Fuzzy Sets and Systems 161 (2010), 735–749), and
Harding–Romanowska, [Varieties of Birkhoff systems I](https://math.nmsu.edu/people/personal-pages/files/2015-Varieties-of-Birkhoff-systems-part-I.pdf).
Those inspected sources do not supply a clone recognition theorem matching the
marked essential-source problem. Standard three-valued hazard-free monotone
formula results also do not provide one: collapsing N and P erases precisely
the source relevance distinction detected by the counterexamples above.
