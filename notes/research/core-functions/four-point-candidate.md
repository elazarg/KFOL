# Four-point interpolation without a core minorant

`four-point-candidate.py` is a standalone, standard-library Python calculation.
Run it without arguments to recompute the maximal functions, or with `--quick`
to evaluate the actual terms and check the complete forbidden subpower only.
`Core.exists_four_local_without_core_minorant` in `Core/MinorantFivePatches` proves the
uniform result in Lean, using the symbolic cover in `Core/MinorantFive` and
the finite certificate in `Core/MinorantFiveCertificate`. The independent
calculation below also checks maximality of the seven-value witnesses.

The JSON field `lean_family` contains the exact five expressions used in the
Lean theorem: unions of respectively 4,6,6,5,3 components (24 in total).
The separate field `maximal_family` retains the larger discovery family solely
for the maximality checks. The common operations of these families need not
coincide. Coherence and critical values below are checked for `lean_family`. The operation code 3 means union, whose fixed
three-owner definition is checked independently. The two repair components are
`(Y ⋆a X) ⋆b Z`, added to the third patch, and that expression `⋆c W`, added to
the fourth patch. They preserve the seven-value functions and repair an extra
passive contribution that the original expressions lost.

On all 16,807 valuations in the seven-value algebra, at least four of the five
expressions agree. Thus their common operation has a common core interpolant
at any four valuations: each valuation excludes at most one expression. Yet
no core operation lies below it. The five critical observations are:

| Inputs X,Y,Z,W,V | Forbidden winner | Common value |
|---|---|---|
| a,b,b,bc,c | a | bc |
| a,b,a,a,a | b | a |
| c,c,b,c,a | b | ac |
| c,bc,b,a,b | a | bc |
| b,c,bc,bc,a | a | bc |

Here concatenation denotes a set of named roles. The complete subalgebra on
these five rows, generated by the five input columns, has 830 tuples. Every
tuple contains a forbidden winner. The program computes this closure without
pruning. Since every core term's row tuple belongs to the closure, simultaneous
avoidance is impossible. Every proper deletion of a row admits its corresponding
input projection.

The default run separately recomputes each greatest full core function satisfying
four of the negative observations. It retains one union-maximal function in
each sampled-row fiber and closes under choice. Separate distributivity of
choice over union makes this exact: every intermediate function is constructed
from projections by choices and unions, and term induction proves exhaustive
coverage at the fixed point. Functions are encoded by 1,215 isolated-source
observations, using the source decomposition already proved in Lean. Each final
coefficient array is compared with independent direct evaluation of the
corresponding `maximal_family` expression on every valuation. Maximality is
not asserted for the pruned Lean family. A terminal product-closure check independently
checks the worklist result.

## Passive markers and the extended coefficient calculation

The actual repaired expressions also agree at least four out of five on all
1,024 formal status cells. Each input is either one of the three named singleton
atoms or its own fresh passive marker. A passive input denotes any winner set
that is none of those named singleton atoms. On a fixed cell, a term reduces to
a union of named atoms and passive inputs. A union containing a passive input
cannot become a named singleton, so the choice branches are preserved when its
marker is replaced by any such input. Equal formal unions therefore give equal
values under every replacement. This explains why the status calculation is
stronger than evaluation on a larger fixed finite carrier; it is still a
computational certificate. `Core/StatusModel` proves its semantic transfer in
Lean, and the kernel checks the finite status calculation and the actual
core-expression correspondence.

The repair was found by extending the source coefficients. Keep the 1,215
observations for the three named winners. Add 1,280 observations for one fresh
observer d: choose its supplying input in five ways, set it to {d}, and assign
all other inputs one of a,b,c,neutral in $4^4$ ways. Neutral is represented by abc
and omits d. The resulting 2,495 bits record the named winners and each passive
input's possible contribution. Only the three named singleton profiles are
needed. At a root owned by r, coefficients are the child union with the bits
killed by a child r-singleton removed; the fresh observer always differs from r.
The same sampled-row fiber calculation then applies.

The extended calculation produced compatible maximum vectors. The repaired
explicit terms give independent actual witnesses for the needed coherent
family; the full maximality of every extended vector has not been certified
by an independently evaluated term witness. The seven-value maxima, in contrast,
are all checked against the supplied expressions by the program.
