# Five-point interpolation is insufficient: finite research candidate

Run `python3 five-point-candidate.py`. The checker and `candidate_support.py`
use only the Python standard library. The adjacent JSON contains six actual
core expressions, represented as unions of short components. The default run
evaluates all expressions and computes the complete six-row subpower.
`--maximal` additionally recomputes their full maximal functions by sampled-row
fiber closure. No Lean theorem is claimed for this candidate.

On all 16,807 inputs in the seven-value algebra, at least five of the six
expressions agree. Their common operation F therefore has one core interpolant
at every five valuations: each valuation excludes at most one of six terms.
The first supplied expression is pointwise contained in F, so F has a core
minorant. Nevertheless, F is not itself a core operation.

The six critical rows are:

| Inputs X,Y,Z,W,V | Required observation | F |
|---|---|---|
| c,b,c,a,b | a present | abc |
| b,b,bc,a,c | a absent | bc |
| b,a,c,c,c | b absent | ac |
| c,a,b,c,b | a absent | bc |
| c,bc,bc,b,a | a absent | bc |
| a,c,b,c,ac | b absent | ac |

Concatenation denotes a set. The complete six-row subpower, generated by the
five input columns under coordinatewise choices, has 7,260 tuples. None meets
the positive observation and all five exclusions. Every core term yields a
tuple in this closure, so no term equals F. Dropping any one negative constraint
admits a tuple meeting the remaining requirements; the checker verifies this.
The common operation follows the five disjoint source-deletion contexts below
and otherwise returns the union of all inputs:

- If X=Y=b and V=c, suppress a contributed by W.
- If Y=a and Z=W=V=c, suppress b contributed by X.
- If X=W=c and Z=V=b, suppress a contributed by Y.
- If X=c and W=b, suppress a contributed by V.
- If X=a and Y=W=c, suppress b contributed by Z.

The raw greatest function obeying all five exclusions loses more memberships
than the common operation, including a at the positive row. The first actual
term in the JSON loses ten additional source bits compared with that raw
maximum. These missing bits are irrelevant: direct evaluation establishes
five-of-six coherence and the core-minorant assertion using the actual term,
without assuming it is maximal. The other five expressions match the raw
maximal functions exactly.

The supplied expressions fail five-of-six coherence on four of the 1,024
formal passive-marker cells. Consequently this artifact currently states the
result for exactly three roles. The repaired four-point candidate has a
separate successful uniform-marker check; that result should not be confused
with this one.
