# Five-point interpolation does not imply core realizability

Run `python3 five-point-candidate.py`. The checker and `candidate_support.py`
use only the Python standard library. The adjacent JSON retains the positive
source index 253 and negative indices 288,444,91,349,633, and the six exact factored expressions
used by
`Core.exists_five_local_noncore` in `KFOL/Core/FivePointInterpolation.lean`.
Each is stored as a one-element component list under `lean_family`. Together
they have 133 logical operations, counting a union as one.

An integer 0..4 denotes X,Y,Z,W,V. A node `[r,s,t]` denotes owned choice for
r=0,1,2 (owners a,b,c), and union for r=3. A component list denotes its union.
The checker verifies the three-owner core expression for union separately.

The checker checks the exact Lean family on all 1,024 formal status cells
and all 16,807 inputs in the three-role seven-value algebra. In a formal cell,
each input is either a, b, c, or its own distinct passive marker. At least five
of the six expressions agree at every cell, and the first expression is
contained in their common value F. Lean's status interpretation proves the
corresponding statement for arbitrary role types containing three distinct
roles. Thus F has a core interpolant on every set of at most five valuations,
and has a core minorant, while F itself is not core.

The six critical rows are:

| Inputs X,Y,Z,W,V | Required observation | F |
|---|---|---|
| c,b,c,a,b | a present | abc |
| b,b,bc,a,c | a absent | bc |
| b,a,c,c,c | b absent | ac |
| c,a,b,c,b | a absent | bc |
| c,bc,bc,b,a | a absent | bc |
| a,c,b,c,ac | b absent | ac |

Concatenation denotes a set. The complete six-row subpower, generated by the
five input columns under coordinatewise choices, has 7,260 tuples. None meets
the positive observation and all five exclusions. Every core term yields a
tuple in this closure, so no term equals F. Dropping any one negative
constraint admits a tuple meeting the remaining requirements. The default
checker recomputes this unpruned closure independently of source coefficients.
The uniform six-row exclusion is separately proved in Lean.

The default checker also evaluates the three-role clipped family
`reset(P_i,P_0)`. Here `reset(A,B)` returns B when B is a singleton, and A∪B
otherwise; its finite-owner core compilation is checked directly. The clipped
expressions still agree five at a time, have exactly the same singleton
profiles as P_0, and retain all six critical common values. This finite
regression is separate from the general finite-role clipping result.

## This witness is not source-separable

At three owners, the same exact family evaluations give, at observer a
and marked source W,

| Inputs X,Y,Z,W,V | Common output |
|---|---|
| b,b,bc,a,c | bc |
| b,b,bc,a,bc | abc |
| bc,bc,bc,a,c | abc |

The latter two rows retain respectively just the first row's pure-b and
pure-c atomic flags; the other passive inputs are neutral bc. Both pure
ports are true, but the mixed source-a coefficient is false. The clipped
family has the same three values. Thus neither three-owner five-point
candidate is source-separable. Its locality theorem alone does not settle
whether a bounded interpolation test could suffice within the separable
subclass. This table is a direct finite evaluation of the pinned
expressions, not an additional Lean theorem.
